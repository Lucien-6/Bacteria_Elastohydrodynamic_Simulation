## 1. Physical Problem

The simulator models a bacterial body with flexible pili or flagella settling in a Stokes-flow environment:

- **Body:** rigid capsule, sphere-like body, or imported custom 3D point cloud.
- **Pili / flagella:** one or more inextensible Kirchhoff elastic rods.
- **Fluid:** zero-Reynolds-number Stokes flow.
- **Coupling:** hydrodynamic interactions between all body and pili points are retained through a global mobility solve.

The default parametric body is a capsule with two hemispherical caps and a cylindrical midsection. In custom geometry mode, both the body and pili are imported from user-provided point clouds; mixing custom and parametric geometry in either direction is rejected by `validate_simulation_params.m` when the mixed fields reach the validator (inline or programmatic `cfg`, or JSON loaded into `cfg` and passed through `run_simulation.m`). Note: in JSON parametric mode, `load_sim_config.m` does **not** read a top-level `custom_geometry` block into `cfg`, so such stray keys are silently ignored at load time rather than validated—remove them from the JSON file or switch to `geometry_mode: "custom"`.

An imported pilus curve is converted once to a canonical equal-chord polygon:
consecutive duplicates are removed, a PCHIP parameter curve is formed, and
nested scalar root solves choose monotonically increasing parameters with a
common endpoint-to-endpoint chord length.  Reference nodes, all material
directors, and intrinsic curvature are derived from that same polygon.
Initial body orientation then applies one rigid rotation to every reference
director before Euler angles are recovered, preserving objectivity for curved
stress-free rods.  All pili share the global \(E\) and \(r_{\mathrm{pili}}\);
there is no per-pilus stiffness parameter.

Parametric pili are generated by `pili_type_building.m` as a template along
\(+x\) (bending plane \(xy\)) and placed on one of 14 body attachment sites by
`pili_building.m`. Since v8.3.0 every site map is a proper rotation
\(R=[\mathbf{c}_1,\mathbf{c}_2,\mathbf{c}_1\times\mathbf{c}_2]\) (outward
direction \(\mathbf{c}_1\), bending direction \(\mathbf{c}_2\)) followed by a
translation, and the optional deflection matrices \(R_z(\theta)\), \(R_x(\gamma)\)
are right-handed. Earlier versions used coordinate swaps with \(\det=-1\) at
sites 1, 2, 5, 7, 10, 11, 14 and a left-handed \(R_x\), which mirrored chiral
templates (conical spiral) and the twist sense of `deflection_x`; planar
templates without `deflection_x` are placed identically in both versions.

## 2. Main Methods

| Component | Method | Main source |
| --- | --- | --- |
| Body hydrodynamics | Regularized Stokeslet Method (RSM) on body surface points | Cortez et al. (2005) |
| Pili hydrodynamics | Regularized Stokeslet Segments (RSS) with exact segment integration | Cortez (2018) |
| Pili twist-flow coupling | Regularized rotlet segments | Cortez (2018) |
| Pili elasticity | Kirchhoff elastic rod with Euler-angle directors | Walker (2020) |
| Body orientation | Quaternion kinematics | Project implementation |
| Time integration | MATLAB `ode15s` with event-driven segmenting | Project implementation |

The key numerical advantage is that RSS integrates the regularized Stokeslet kernel along each straight pilus segment exactly. This separates segment length from regularization radius, allowing roughly `10` segments per micrometer for typical pili while keeping hydrodynamic interactions resolved.

## 3. Nondimensionalization

The body semi-major axis is used as the reference length:

| Quantity | Symbol | Definition |
| --- | --- | --- |
| Length | $L_0$ | body `major_axis` (parametric); `L_0_override` or body-derived suggestion (custom) |
| Bending stiffness | $EI$ | $E\pi r_{\mathrm{pili}}^4/4$ |
| Time | $T_0$ | $8\pi\mu L_0^4/EI$ |
| Velocity | $U_0$ | $L_0/T_0$ |
| Force | $F_0$ | $EI/L_0^2$ |

Important dimensionless parameters are:

- Elastic-gravity number: $E_g = F_{\mathrm{sink}}L_0^2/EI$.
- Pili slenderness: $\varepsilon = r_{\mathrm{pili}}/L_0$.
- Poisson ratio: $\sigma$, supplied by the user.

The sinking force (dimensional) is

```math
F_{\mathrm{sink}} = (\rho_{\mathrm{bac}} - \rho_{\mathrm{fluid}})\, V_{\mathrm{body}}\, g,
```

where $V_{\mathrm{body}}$ is the capsule volume in parametric mode or the alpha-shape volume in custom mode. Gravity enters the ODE right-hand side as $\mathbf{R}_{1:3} = -E_g\,\hat{\mathbf{g}}$ with $\hat{\mathbf{g}} = [0,0,-1]^\mathsf{T}$.

The root–body gap (dimensional) is

```math
\mathrm{dis} = 1.1\,(\varepsilon_{\mathrm{body}}L_0 + r_{\mathrm{pili}}),
```

passed to `pili_building` / `custom_pili_building` to keep regularized kernels separated at the pilus root. It uses the body regularization length of §5.1 and the physical pilus radius, so it does not depend on `hydro_radius_factor` (§5.2).

Additional model inputs use the same reference scales:

- Background flow velocity: $\mathbf{u}_{\mathrm{bg}}^\ast = \mathbf{u}_{\mathrm{bg}}/U_0$.
- Integrated active moments: $\mathbf{M}^\ast = \mathbf{M}_{\mathrm{phys}}L_{\mathrm{pili}}/EI$.
- Intrinsic curvature: stored on the same nondimensional arclength scale as the Euler-angle curvature fields.

## 4. State Vector and Geometry

The full state contains body position, body orientation, and each pilus rod state:

```math
\mathbf{Z} =
\left[
\mathbf{X}_{\mathrm{cm}},
\mathbf{q},
\boldsymbol{\theta}_1,
\boldsymbol{\phi}_1,
\boldsymbol{\psi}_1,
\ldots,
\boldsymbol{\theta}_M,
\boldsymbol{\phi}_M,
\boldsymbol{\psi}_M
\right].
```

The body quaternion $\mathbf{q}$ represents the body-to-lab rotation and is advanced with:

```math
\frac{d\mathbf{q}}{dt}
= \frac{1}{2}
\begin{bmatrix}
0 \\
\boldsymbol{\Omega}
\end{bmatrix}
\otimes \mathbf{q}.
```

Here $\boldsymbol{\Omega}$ is the **body angular velocity in the lab frame**, taken from `z_dot(4:6)` of the coupled solve (`quat_kinematics.m`).

For each pilus, Euler angles define the material directors `(d1, d2, d3)`, where `d3` is the segment tangent. [`reconstruct_geometry.m`](../src/geometry/reconstruct_geometry.m) maps `Z` to lab-frame body points, pilus nodes, directors, and auxiliary geometry used by the hydrodynamic solve.

## 5. Hydrodynamics

### 5.1 Body RSM

Body surface forces are represented by the Cortez regularized Stokeslet kernel:

```math
\mathbf{S}^{\varepsilon}(\mathbf{r})
=
\frac{
\left(\lVert\mathbf{r}\rVert^2 + 2\varepsilon^2\right)\mathbf{I}
+ \mathbf{r}\mathbf{r}^{\mathsf{T}}
}{
\left(\lVert\mathbf{r}\rVert^2 + \varepsilon^2\right)^{3/2}
}.
```

The body regularization length defaults to:

```math
\varepsilon_{\mathrm{body}} = h_{\mathrm{mean}}/2.6667.
```

where `h_mean` is the mean nearest-neighbor spacing of the body surface points in nondimensional units. This default was calibrated by the `N_body x eps_body` Stokes-sphere sweep and can be overridden by `body.eps_body` in JSON or `cfg.eps_body` in MATLAB.

### 5.2 Pili RSS

For a straight segment from $\mathbf{y}_0$ to $\mathbf{y}_1$, RSS evaluates the velocity contribution of a linearly varying force density:

```math
\mathbf{u}(\mathbf{x})
=
\mathbf{M}_1\mathbf{f}_0
+ \mathbf{M}_2\mathbf{f}_1.
```

The matrices `M1` and `M2` include exact segment integration weights. No additional trapezoidal length factor is applied to the RSS segment columns. The required `T_{n,q}` integrals are evaluated by the Cortez (2018) recurrence.

For pili, the regularization length is tied to the physical radius by a calibration factor $\beta$ (`hydro_radius_factor`):

```math
\varepsilon_{\mathrm{pili}} = \beta\, r_{\mathrm{pili}}/L_0,
\qquad \beta = \sqrt{2}\ \text{(default)}.
```

Unlike body RSM regularization, this length is not a numerical parameter to send toward zero: it sets the hydrodynamic radius of the pilus.  A centreline line of regularized singularities is not a no-slip cylinder, and its effective radius differs between translation and axial rotation, so $\beta=1$ (used up to 8.5.1) is not a calibrated choice.  The bending stiffness always uses the physical $r_{\mathrm{pili}}$, and the root gap `dis` is computed from it as well.  For the Cortez (2018) 7/2 blob, tested on a straight filament at its mid-point ($r_{\mathrm{pili}}/L_{\mathrm{pili}}=3\times10^{-3}$, 100 segments):

- **Axial twist.**  The regularised-rotlet-segment line has the drag $\xi_t=2\pi\mu\varepsilon^2$ per unit length (checked numerically, ratio $1.0000$), whereas a no-slip cylinder has $4\pi\mu r^2$ (Walker et al. 2020, Eq. 24; Maxian et al. 2022, Sec. II A 3).  They agree for $\varepsilon=\sqrt2\,r$; with $\beta=1$ the twist drag was half of the cylinder value.
- **Translation.**  The regularization radius of the Rotne–Prager–Yamakawa line, $\hat a=r\,e^{3/2}/4\approx1.12\,r$, reproduces the slender-body theory of a cylinder of radius $r$ (Maxian et al. 2021–2023).  For the present blob the same translational mobility, perpendicular and parallel, is obtained for $\varepsilon=\sqrt{e}\,r\approx1.649\,r$ (analytic and numerical).  With $\beta=\sqrt2$ the mid-filament mobility is $2.4\,\%$ (perpendicular) and $2.9\,\%$ (parallel) above that reference, with $\beta=1$ it was $7.9\,\%$ and $9.4\,\%$ above.

$\beta=\sqrt2$ is therefore the default compromise: exact cylinder twist drag and translation within about $3\,\%$.  Use $\beta=\sqrt e$ for exact translation (twist drag then $36\,\%$ above the cylinder value), or $\beta=1$ to reproduce versions up to 8.5.1.  For pure sedimentation of a single pilus the sink distance changed by $0.13\,\%$ between $\beta=1$ and $\beta=\sqrt2$; in the motor example case (`D4`) the body counter-rotation angle over the run changed by a factor of $1.95$ ($0.0976\to0.190$ rad).

### 5.3 Rotlet Segments

Twist-induced flow is included through regularized rotlet segments:

```math
\mathbf{u}(\mathbf{x})
=
-L
\left(
c_a[\mathbf{x}_0]_{\times}
+ c_b[\mathbf{v}]_{\times}
\right)
\boldsymbol{\tau}.
```

where `tau` is the segment torque density. The implementation stores the Cortez (2018) full-curl rotlet segment kernel as `M_rotlet`; when this block is coupled reciprocally to Stokeslet translation, the physical standard-rotlet convention is enforced through the factor `0.5*M_rotlet`.

## 6. Coupled Linear System

At each ODE right-hand-side call, the simulator assembles:

```math
\mathbf{L}\dot{\mathbf{z}} = \mathbf{R},
```

with:

```math
\mathbf{L} = -\mathbf{B}\mathbf{A}\mathbf{Q}.
```

Here \(\mathbf{Q}\) maps the generalised rates to point velocities and segment spin rates, \(\mathbf{A}\) maps those velocities to the force and torque densities on the fluid (the inverse of the grand mobility below, applied by linear solves and never formed), and \(\mathbf{B}\) collects the densities into the balance equations.

Since v7.6.0, axial twist no longer uses a local RFT torsional resistance. The translational and axial-spin unknowns are coupled through the grand mobility:

```math
\begin{bmatrix}
\mathbf{u} \\
\omega_\parallel
\end{bmatrix}
=
\begin{bmatrix}
\mathbf{M}_{\mathrm{weighted}} & \mathbf{C}_{\mathrm{forward}} \\
\mathbf{C}_{\mathrm{reverse}} & \mathbf{M}_{\mathrm{twist}}
\end{bmatrix}
\begin{bmatrix}
\mathbf{f} \\
\mathbf{m}
\end{bmatrix},
```

where `M_twist` is the non-local segment-integral axial rotation mobility and

```math
\mathbf{C}_{\mathrm{forward}}
=
\tfrac{1}{2}\mathbf{M}_{\mathrm{rotlet}}\mathbf{D}_{\mathrm{twist}},
\qquad
\mathbf{C}_{\mathrm{reverse}}
=
\mathbf{W}_m^{-1}\mathbf{C}_{\mathrm{forward}}^{\mathsf T}\mathbf{W}_f.
```

Here \(\mathbf{W}_f\) repeats the body/RSS quadrature weight for each
Cartesian force component and
\(\mathbf{W}_m=\operatorname{diag}(L_s)\) uses the actual segment lengths.
Thus
\(\mathbf{W}_f\mathbf{C}_{\mathrm{forward}}
=\mathbf{C}_{\mathrm{reverse}}^{\mathsf T}\mathbf{W}_m\), which is the
discrete virtual-power form of Lorentz reciprocity.  An ordinary transpose
would be correct only when both measures were identical.  The `1/2` factor
converts Cortez's full-curl rotlet segment kernel to the physical
standard-rotlet convention. The code applies the inverse action by Schur
complement:

```math
\mathbf{S}_{\mathrm{twist}}
=
\mathbf{M}_{\mathrm{twist}}
-
\mathbf{C}_{\mathrm{reverse}}
\mathbf{M}_{\mathrm{weighted}}^{-1}
\mathbf{C}_{\mathrm{forward}},
```

so the same coupled operator is used in the main linear system and in background-flow corrections.

`M_twist` maps torque density to angular velocity and is therefore also
self-adjoint in the line measure:
\(\mathbf{W}_m\mathbf{M}_{\mathrm{twist}}
=\mathbf{M}_{\mathrm{twist}}^{\mathsf T}\mathbf{W}_m\).
The implementation enforces this relation using each segment's endpoint
distance; it does not assume equal segment lengths across different pili.

The main blocks are:

- `Q_global`: maps generalized rates to body and pilus node velocities.
- `M_weighted`: full translational hydrodynamic mobility matrix, including body RSM and pili RSS blocks.
- `M_twist`: non-local axial twist mobility.
- `D_twist`: embeds scalar axial torque density into segment-aligned 3D rotlet vectors.
- `C_forward`, `C_reverse`: weighted-adjoint translation/twist coupling blocks with physical standard-rotlet scaling.
- `B_global`: maps distributed forces and line-integrated torques into global force, moment, and pilus moment-balance equations.
- `R`: gravitational force, elastic moments, active moments, background-flow corrections, and motor torque terms.

**Global angular-momentum balance (since v7.6.0).** The total hydrodynamic torque the swimmer exerts on the fluid is the sum of the Stokeslet moment and the line-integrated net rotlet torque,

```math
\mathbf{T} = \sum_i \mathbf{r}_i \times \mathbf{f}_i + \sum_s L_s \mathbf{m}_s,
```

because `m_s` is a torque density on segment `s`. Therefore the moment rows of `B_global` include both `sum(r x f)` and `sum(L_s m_s)`. This makes a force/torque-free swimmer exactly torque-free and yields the correct body counter-rotation for motor-driven or spinning pili.

Solves use MATLAB decomposition / LU factorization rather than explicit matrix inversion.

### 6.1 Fast Body-Frame Block Schur Complement and Frozen-Hydrodynamics Jacobian (v10.0.0)

Because the cell body is rigid, its self-interaction RSM mobility block \(\mathbf{M}_{BB}^{\mathrm{loc}}\) (\(3N_{\mathrm{body}} \times 3N_{\mathrm{body}}\), symmetric positive definite) is constant in the body-local frame throughout the simulation. During initialization, `build_body_precomp` computes its Cholesky decomposition \(\mathbf{M}_{BB}^{\mathrm{loc}} = \mathbf{L}_{BB}\mathbf{L}_{BB}^{\mathsf T}\) and its action on the six rigid-body kinematic columns \(\mathbf{U}_{QB}^{\mathrm{loc}} = (\mathbf{M}_{BB}^{\mathrm{loc}})^{-1}\mathbf{Q}_{B,6}^{\mathrm{loc}}\) once. At every RHS evaluation, `build_coupled_lin_sys` transforms pilus coordinates and tangents into the body frame, assembles only the configuration-dependent blocks \((\mathbf{M}_{PB}, \mathbf{M}_{BP}, \mathbf{M}_{PP}, \mathbf{C}_{\mathrm{twist}}, \mathbf{M}_{\mathrm{twist}})\) via `build_pili_mobility_blocks`, and eliminates all \(3N_{\mathrm{body}}\) body unknowns algebraically via the block Schur complement

```math
\mathbf{S}_{PP} = \mathbf{M}_{PP} - \mathbf{M}_{PB}(\mathbf{M}_{BB}^{\mathrm{loc}})^{-1}\mathbf{M}_{BP}.
```

This reduces the per-step dense LU factorization from \(O((3N_{\mathrm{body}} + 3N_{\mathrm{pili}})^3)\) to \(O((3N_{\mathrm{pili}})^3)\) while remaining algebraically equivalent to the dense assembly (machine-precision agreement modulo conditioning, verified by `validation/cpc_performance_benchmark.m`). For bare-body runs (\(M = 0\)), the precomputed \(6\times 6\) resistance matrix is rotated directly into the laboratory frame (`99x` faster at \(N_{\mathrm{body}}=300\)).

For stiff `ode15s` Newton iterations, the dominant \(O(N_k^4)\) stiffness arises from the local Kirchhoff elastic restoring moments \(\partial \mathbf{R}/\partial \mathbf{Z}\) while the hydrodynamic resistance \(\mathrm{lin\_sys}(\mathbf{Z})\) varies smoothly at \(O(1)\). `ode_coupled_jacobian` therefore assembles and LU-factors \(\mathrm{lin\_sys}(\mathbf{Z})\) once, evaluates \(\partial \mathbf{R}/\partial (\theta,\phi,\psi)\) using stride-3 banded graph colouring for local stencils (plus individual root columns and exact linearized motor torque–speed feedback), and computes the Jacobian via one multi-RHS back-substitution—achieving 75×–517× Jacobian speedups without altering the ODE RHS or local error control, with automatic fallback to finite-difference Jacobians if Newton fails. Across Brownian restarts, `LaggedJacobian` reuses the cached Jacobian up to `jacobian_max_age` intervals and refreshes via `ode_coupled_jacobian` on demand or after basis rotations.

## 7. Elastic Rod Moments

Pili are treated as Kirchhoff rods. The Darboux vector is:

```math
\mathbf{U}
=
\kappa_1\mathbf{d}_1
+ \kappa_2\mathbf{d}_2
+ \kappa_3\mathbf{d}_3,
```

with director evolution:

```math
\mathbf{d}_{\alpha}' = \mathbf{U}\times\mathbf{d}_{\alpha}.
```

The curvature components used in [`compute_pili_elastic_moments.m`](../src/physics/compute_pili_elastic_moments.m) are:

```math
\kappa_1
=
\mathbf{d}_3\cdot\mathbf{d}_2'
- \kappa_{1,0},
```

```math
\kappa_2
=
\mathbf{d}_1\cdot\mathbf{d}_3'
- \kappa_{2,0},
```

```math
\kappa_3
=
\frac{
\mathbf{d}_2\cdot\mathbf{d}_1'
- \kappa_{3,0}
}{1+\sigma}.
```

Intrinsic curvature can be configured per pilus as `frozen`, `zero`, `constant`, or `helix`. Active moments can be disabled, prescribed as a traveling wave, or supplied by custom configuration.

### Discrete curvature stencil (v8.3.0)

Directors are stored per segment (segment \(i\) spans \(s\in[(i-1)\,\Delta s,\ i\,\Delta s]\), \(\Delta s = 1/N\)) while the moment balance is written at nodes. The shared operator [`compute_pili_curvature.m`](../src/physics/compute_pili_curvature.m) evaluates the three components at node \(i\) as

```math
\kappa_1(s_i) = \mathbf{d}_3^{(i)}\cdot\frac{\mathbf{d}_{2,i}-\mathbf{d}_{2,i-1}}{\Delta s},\qquad
\kappa_2(s_i) = \mathbf{d}_1^{(i)}\cdot\frac{\mathbf{d}_{3,i}-\mathbf{d}_{3,i-1}}{\Delta s},\qquad
\kappa_3(s_i) = \mathbf{d}_2^{(i)}\cdot\frac{\mathbf{d}_{1,i}-\mathbf{d}_{1,i-1}}{\Delta s},
```

where \(\mathbf{d}_{\alpha,i}\) are the **segment** directors and \(\mathbf{d}_\alpha^{(i)}\) is the **nodal** director obtained by the SVD polar mean of the two segment frames adjacent to node \(i\) ([`compute_node_directors.m`](../src/physics/compute_node_directors.m)). Segments \(i-1\) and \(i\) are centred at \(s_i \mp \Delta s/2\), so the difference quotient is a central estimate of \(\mathbf{d}_\alpha'(s_i)\) collocated with the nodal director it is projected onto; the scheme is therefore \(O(\Delta s^2)\). The pre-8.3.0 implementation differenced the nodal directors themselves, which centred the derivative at \(s_i - \Delta s/2\) and reduced the projection to \(O(\Delta s)\) (verified numerically on an analytic constant-Darboux-vector frame: observed orders 2.00 vs 0.98). Node 1 borrows the node-2 stencil and is subsequently replaced by the root boundary condition; node \(N+1\) is moment-free and unused. The intrinsic curvature `kb0` in `init_coupled_params.m` is produced by the same operator, so a `frozen` pilus is an exact zero-moment equilibrium at \(t=0\) (residual \(\sim 10^{-13}\)).

## 8. Root Coupling and Motor Torque

Each pilus root supports two boundary modes:

- `clamped`: root bending and twist angles are locked to the body frame.
- `free_torsion`: root bending angles remain locked, but the root twist angle `psi_1` evolves dynamically.

In `free_torsion`, the root `d3` moment row is the axial moment balance of the whole filament about the root; its right-hand side is the boundary torque transmitted by the body (the motor torque, or zero for a frictionless bearing) — see "Root twist row" below. As of v7.3.0, no explicit motor reaction term is added to `R_global(4:6)`. Those rows are the angular-momentum balance for the entire coupled body-pilus hydrodynamic system, so a motor torque exchanged internally between body and pilus cancels in the system sum. The body angular response is still present, but it emerges implicitly from the coupled Stokes solve and the root kinematic constraints.

### Motor torque-speed law (v8.2.0)

The effective motor torque follows the linear torque-speed relation of the bacterial flagellar motor (Berg & Turner 1993; Berg 2003), written in the rotor speed relative to the cell body:

$$\tau_{\mathrm{eff}} = \tau_{\mathrm{motor}}\left(1 - \frac{\omega_{\mathrm{rel}}}{\omega_{\max}}\right),\qquad
\omega_{\mathrm{rel}} = \operatorname{sign}(\tau_{\mathrm{motor}})\,\Big[\big(\dot\psi_1 + \cos\theta_1\,\dot\phi_1\big) - \boldsymbol{\Omega}_{\mathrm{body}}\cdot\mathbf{d}_3^{(1)}\Big].$$

$\dot\psi_1 + \cos\theta_1\dot\phi_1$ is the full axial angular velocity of segment 1 in the Walker Euler-angle kinematics (the same expression that defines the twist-rate rows of the linear system); subtracting $\boldsymbol{\Omega}_{\mathrm{body}}\cdot\mathbf{d}_3^{(1)}$ makes the speed frame-independent and equal to the rotor-stator relative rotation that the motor actually senses. The sign factor measures the speed in the driving direction, so one law serves CW and CCW motors. The law is asymmetric: forced backward rotation ($\omega_{\mathrm{rel}}<0$) raises the torque above stall, and $\omega_{\mathrm{rel}}>\omega_{\max}$ gives a braking torque. Since $z_{\dot{}}$ is affine in the motor torques, $\omega_{\mathrm{rel}} = a + B\tau$ with $a$ the motor-free solution and $B$ the response to unit torques (both from one factorisation of `lin_sys`), and the self-consistent torques solve the small linear system $(I + \operatorname{diag}(|\tau_{\mathrm{motor}}|/\omega_{\max})B)\,\tau = \tau_{\mathrm{motor}} - \operatorname{diag}(|\tau_{\mathrm{motor}}|/\omega_{\max})\,a$ exactly.

Sign convention: because `R_global` stores the negative of the applied generalised force, the motor torque enters its $\psi_1$ row as $-\tau$; a positive `torque_pN_nm` therefore drives the rotor in the right-handed sense about the outward root tangent $\mathbf{d}_3$ (counter-clockwise viewed from the filament tip toward the cell).

### Root twist row for `free_torsion` (v8.4.0)

Row $i$ of the pilus moment balance is the balance of the rod portion $[s_i, 1]$ about node $i$:

```math
\mathbf{M}(s_i) + \int_{s_i}^{1}\big(\mathbf{x}-\mathbf{x}_i\big)\times\mathbf{f}\,\mathrm{d}s + \int_{s_i}^{1}\mathbf{m}\,\mathrm{d}s = \mathbf{0},
```

where $\mathbf{M}(s_i)$ is the internal moment exerted by $[0,s_i)$ on $[s_i,1]$. For an interior node this is the Kirchhoff moment $EI(\kappa_1\mathbf{d}_1+\kappa_2\mathbf{d}_2)+GJ\kappa_3\mathbf{d}_3$ plus the integrated active moment. At the root node, $[0,s_1)$ is the cell body, so $\mathbf{M}(0)$ is the torque the body applies to the rod: an unknown reaction for `clamped` (the three rows become kinematic constraints) and, for `free_torsion`, $\mathbf{M}(0)\cdot\mathbf{d}_3 = \tau_{\mathrm{eff}}$ (zero for a frictionless bearing). The discrete $\kappa_3$ available at node 1 is evaluated between segments 1 and 2 and is already the internal moment used by the node-2 balance. Before v8.4.0 it was nevertheless also added to the root row; subtracting the node-2 row shows that the motor torque was then balanced by the hydrodynamic torque on segment 1 alone, so the steady rotor speed of a straight filament scaled as $N$ times the physical value (verified: $N=10$ gives $8.47\times10^4$ vs. $8.84\times10^3$ rad/s after the fix; the twist profile is linear from node 2 to the tip with $GJ\kappa_3(s_2)=\tau_{\mathrm{eff}}(1-1/N)$). The root rows of `compute_pili_elastic_moments.m` and `coupled_active_moment.m` are now zero for both coupling modes, and the `free_torsion` $\psi_1$ row carries only the boundary torque. Consequences: a free bearing without a motor enforces zero net axial hydrodynamic torque on the filament (a purely internal twist wave cannot spin it), and with a motor the steady speed of a straight filament is $\omega=\tau_{\mathrm{eff}}/(\xi_t L)$ with $\xi_t = 2\pi\mu\epsilon_{\mathrm{pili}}^2$ for the regularised-rotlet-segment line of the Cortez (2018) 7/2 blob; with the default $\epsilon_{\mathrm{pili}}=\sqrt2\,r_{\mathrm{pili}}$ (section 5.2) this equals the no-slip-cylinder value $4\pi\mu r_{\mathrm{pili}}^2$, whereas $\epsilon_{\mathrm{pili}}=r_{\mathrm{pili}}$ (versions up to 8.5.1) gave half of it; the simulator reproduces the coefficient $2\pi\mu\epsilon^2$ to $<10^{-3}$.

## 9. Background Flow

Background flow is evaluated as a prescribed steady velocity field and incorporated through the hydrodynamic correction:

```math
\mathbf{R}
\leftarrow
\mathbf{R}
- \mathbf{B}\mathbf{A}\,\mathbf{u}_{\mathrm{bg}},
```

with the operator \(\mathbf{A}\) of §6: the fluid loads depend on the velocity relative to the background flow, \(\mathbf{A}(\mathbf{Q}\dot{\mathbf{z}} - \mathbf{u}_{\mathrm{bg}})\).

Supported flow types are:

- `off`: no background flow.
- `uniform`: constant velocity with user-defined direction.
- `shear_z`: finite-thickness clipped shear layer with user-defined flow direction, shear axis, and thickness.  Incompressibility requires the normalized flow and shear directions to be orthogonal; validation rejects `abs(dot)>1e-12`.

Inside the unclipped shear layer,
\(\mathbf{u}=U\,\hat{\mathbf d}(\hat{\mathbf s}\cdot\mathbf{x})/H\),
so \(\nabla\cdot\mathbf{u}=(U/H)\hat{\mathbf d}\cdot\hat{\mathbf s}\).
Orthogonality is therefore a mass-conservation condition, not merely a
preferred coordinate convention.

## 10. Brownian Dynamics

When Brownian motion is enabled, the observation window is divided into
Brownian intervals of length `dt_B` (the last one uses the actual remainder).
Since v8.5.0 the body-only thermal motion is realised as a **constant
generalised thermal force** acting on the body throughout each interval
("force realisation"), rather than as a displacement kick applied between
deterministic segments:

1. At the start of each interval, compute the effective body mobility by
   probing the full deterministic body-pili system (Section 10.1).
2. Draw the frozen-mobility Euler–Maruyama increment \(\delta\mathbf{U}\)
   and convert it into the generalised force \(\mathbf{f}_{\mathrm{th}}\)
   that would produce it on the frozen system (Section 10.2).
3. Integrate the coupled system with `ode15s` over the interval with
   \(\mathbf{f}_{\mathrm{th}}\) added to the six body rows of the right-hand
   side (`ode_coupled_rhs` Step 8a); the pili respond to the body's thermal
   motion through the same hydrodynamic and elastic coupling as to gravity
   or a motor torque.

### 10.1 Effective body mobility

The effective mobility is computed by probing the coupled linear system with six unit generalized body loads:

```math
\mathbf{M}_{\mathrm{eff}}^{\ast}(:,i)
=
\left(\mathbf{L}^{-1}(-\mathbf{e}_i)\right)_{1:6},
\qquad i=1,\ldots,6.
```

The symmetric positive-definite check and any round-off-scale spectral repair
are performed on the dimensionless mobility.  A materially negative
eigenvalue is an assembly error rather than something to clamp.  The repaired
matrix is then converted to physical units by a congruence transformation:

```math
\mathbf{D}_{\mathrm{eff}}
=
k_B T\,\mathbf{M}_{\mathrm{eff,dim}},
```

```math
\mathbf{L}_{\mathrm{eff}}
\mathbf{L}_{\mathrm{eff}}^{\mathsf{T}}
=
2\mathbf{D}_{\mathrm{eff}},
```

```math
\delta\mathbf{U}
=
\mathbf{L}_{\mathrm{eff}}
\boldsymbol{\eta}
\sqrt{\Delta t_B},
\qquad
\boldsymbol{\eta}\sim\mathcal{N}(\mathbf{0},\mathbf{I}_6).
```

Brownian samples come from a run-local random stream and are independent of
geometry-cache creation; exactly six normal deviates are consumed per
interval.

### 10.2 Force realisation of the increment (v8.5.0)

With the effective mobility frozen at the interval start, the generalised
force that produces exactly \(\delta\mathbf{U}\) over \(\Delta t_B\) is

```math
\mathbf{f}_{\mathrm{th}}
=
\mathbf{M}_{\mathrm{eff}}^{-1}\,
\frac{\delta\mathbf{U}}{\Delta t_B},
```

evaluated in the dimensionless generalised units of the coupled system
(rows 1–3 in \(F_0\), rows 4–6 in \(F_0 L_0\); `sample_brownian_body_force`).
It enters the right-hand side with the same sign convention as gravity,
\(\mathbf{R}(1{:}6) \leftarrow \mathbf{R}(1{:}6) - \mathbf{f}_{\mathrm{th}}\),
and is held constant while `ode15s` integrates the interval.  The realised
body increment is therefore \(\int \mathbf{M}_{\mathrm{eff}}(t)\,\mathbf{f}_{\mathrm{th}}\,dt\)
along the actual coupled trajectory rather than the frozen-mobility value.

**Why the pilus root no longer kinks.**  Before v8.5.0 the body pose was
displaced instantaneously at each node and the first pilus segment was then
re-projected onto the moved body while segments \(2\ldots N\) kept their
old orientation.  Each kick therefore injected a curvature discontinuity
between segments 1 and 2 whose amplitude scaled with
\(|\delta\boldsymbol{\Theta}|/\ell\); with \(\ell \ll 1\) this excited
high-wavenumber elastic modes that relaxed on the stiff time scale
\(\ell^4\) and forced `ode15s` into very small steps.  With force
realisation, the body moves continuously and the pili follow through the
coupled solve; the root constraint is never violated, so no spurious mode is
excited.

**Implicit Ito drift.**  The overdamped SDE with configuration-dependent
mobility requires the drift \(k_B T\,\nabla\!\cdot\!\mathbf{M}\) in the Ito
convention.  Expanding the coupled ODE over one interval,

```math
\delta\mathbf{U}_{\mathrm{real}}
=
\mathbf{M}_n\mathbf{f}_{\mathrm{th}}\Delta t_B
+ \tfrac12\,(\partial_j\mathbf{M})\,(\mathbf{M}_n\mathbf{f}_{\mathrm{th}})_j\,\mathbf{f}_{\mathrm{th}}\,\Delta t_B^2
+ \mathcal{O}(\Delta t_B^{3/2}),
```

and using
\(\mathbb{E}[\mathbf{f}_{\mathrm{th}}\mathbf{f}_{\mathrm{th}}^{\mathsf T}]\,\Delta t_B = 2k_BT\,\mathbf{M}_n^{-1}\)
gives

```math
\mathbb{E}\big[\delta\mathbf{U}_{\mathrm{real}}\big]
=
k_B T\,\nabla\!\cdot\!\mathbf{M}\,\Delta t_B
+ \mathcal{O}(\Delta t_B^{3/2}),
\qquad
\operatorname{Cov}\big[\delta\mathbf{U}_{\mathrm{real}}\big]
=
2k_BT\,\mathbf{M}_n\,\Delta t_B
+ \mathcal{O}(\Delta t_B^{3/2}).
```

The mobility gradient sampled along the trajectory thus generates the Ito
drift automatically: the scheme is a consistent weak first-order integrator
of the body-only Ito SDE, and the explicit finite-difference
\(k_B T\,\nabla\!\cdot\!\mathbf{M}\) correction used in v7.5.0–v8.4.0 (twelve
additional coupled solves per node) is no longer applied — adding it again
would double count the drift.

For the present wall-free model the drift has a closed form.  In an unbounded
fluid the effective mobility depends on the body pose only through the
orientation, \(\mathbf{M}_{\mathrm{eff}} = \mathbf{T}\,\mathbf{M}_{\mathrm{shape}}\,\mathbf{T}^{\mathsf T}\)
with \(\mathbf{T}=\mathrm{blkdiag}(\mathbf{R},\mathbf{R})\), so translations do not
enter the divergence.  For an infinitesimal rotation about the lab axis
\(\mathbf{e}_j\) every block changes as
\(\mathbf{A}\to\mathbf{A}+\varepsilon([\mathbf{e}_j]_\times\mathbf{A}-\mathbf{A}[\mathbf{e}_j]_\times)\),
and the drift of row \(i\) is
\(k_BT\sum_j\partial M_{i,R_j}/\partial\theta_j\).  The **rotational rows** vanish
(for symmetric \(\mathbf{M}\)).  The **translational rows** do not vanish in general:

```math
\big(k_BT\,\nabla\!\cdot\!\mathbf{M}\big)_{T,i}
= k_BT\sum_{j,n}\epsilon_{ijn}\,(\mathbf{M}_{TR})_{nj},
```

i.e. \(k_BT\) times the axial vector of the antisymmetric part of the
translation-rotation block.  It is zero when \(\mathbf{M}_{TR}\) is symmetric, in
particular for bodies with a centre of symmetry at the tracking point (the
pilus-free capsule, or symmetric pili arrangements), and non-zero when
\(\mathbf{X}_{cm}\) is not the hydrodynamic centre of the cell: the tracking
point then relaxes towards that centre while the cell rotates.  Its size is of
the order of \(2D_R\) times the offset; for the default capsule with one 3 um
pilus it is about 0.02 um/s (roughly 15 % of the sedimentation speed).  The vector
is fixed in the body frame, so it averages to zero over orientations and gives
no net long-time drift.  The force-realisation scheme generates this term
automatically, because it integrates the actual \(\mathbf{M}(\theta(t))\)
along the interval; a Monte-Carlo test of the scheme as coded on a
two-dimensional rigid body with \(\mathbf{M}_{TR}\neq0\) reproduced
\(k_BT\,\mathbf{R}\mathbf{J}\mathbf{b}\) within 1.3 standard errors, and gave
zero for \(\mathbf{M}_{TR}=0\).  Hence nothing has to be added, and, as above, an
explicit \(k_BT\,\nabla\!\cdot\!\mathbf{M}\) correction would be double counted.
The change of \(\mathbf{M}_{\mathrm{eff}}\) through the pili deforming under the
thermal force during an interval is part of the coupled dynamics, not a drift
correction.

**Scope of the Brownian approximation.**  The hydrodynamic drag of every
pilus affects the probed 6 x 6 body mobility, but in the body-only scheme
pilus internal Euler-angle coordinates receive no stochastic forcing.  Those
modes evolve only under deterministic elasticity, hydrodynamics, active
moments, motor torques, and the thermal force transmitted from the body.
Consequently the body-only scheme is suitable for body translation/orientation
diffusion when internal pilus thermal fluctuations are neglected; it is not a
full coupled equilibrium process and cannot reproduce pilus-mode
equipartition.  Section 10.4 describes the optional thermal forcing of the
slow pilus bending modes (v9.0.0).

**Known approximation — deterministic/stochastic operator consistency.**

The deterministic solve uses the raw hydrodynamic mobility `M_weighted`, which is structurally non-symmetric when `eps_body != eps_pili`: the body RSM block (source `eps = eps_body`) and the pili RSS block (source `eps = eps_pili`) apply different regularisation lengths to the same body–pili pair of entries, so Lorentz reciprocity is not exactly satisfied in the off-diagonal body↔pili coupling blocks. The Brownian covariance path, by contrast, uses the symmetrised effective body mobility `M_eff = 0.5*(M + M')` to satisfy the fluctuation-dissipation requirement of a symmetric diffusion tensor.

This operator splitting therefore relies on the approximation that the non-reciprocal component is small. The implementation measures the relative asymmetry `rel_asym = ||M_eff - M_eff^T||_F / ||M_eff||_F` at every Brownian step and emits a warning when `rel_asym > 1e-3`. For typical mixed-epsilon configurations `rel_asym ~ 1e-5..1e-3`; for pure-RSM (no pili) systems it drops to `<1e-10` (LU round-off only). The Schur-complement extraction from the full `M_weighted` to the 6×6 body block further attenuates the non-symmetry, so the practical impact on the equilibrium distribution is bounded by `rel_asym` itself. For configurations where `eps_body ≈ eps_pili` the approximation becomes exact. Users seeking the strictest statistical fidelity should monitor the `[BROWN]` asymmetry log lines and, if `rel_asym > 1e-2`, consider tightening `eps_body` toward `eps_pili` (or vice versa) provided the body-surface resolution `N_body` is adjusted to keep the RSM leak within tolerance (see §5.1).

### 10.3 Lagged Jacobian in the Brownian ODE restarts (v8.5.1)

This subsection concerns the time integrator only; the model of §10.1–10.2 is
unchanged.  Every Brownian interval restarts `ode15s`.  For the implicit
BDF/NDF step \(\mathbf{y}_{n+1}-\gamma h\,\mathbf{f}(\mathbf{y}_{n+1})=\boldsymbol{\psi}\)
the solver uses a modified-Newton iteration with the matrix
\(\mathbf{W}=\mathbf{I}-\gamma h\,\tilde{\mathbf{J}}\), where \(\tilde{\mathbf{J}}\)
is any approximation of \(\partial\mathbf{f}/\partial\mathbf{y}\).  The iteration
converges iff \(\rho\big(\mathbf{I}-\mathbf{W}^{-1}\mathbf{W}_\text{true}\big)<1\) and,
once converged, solves the same implicit equation whatever \(\tilde{\mathbf{J}}\)
is; the local error estimate and the step/order selection are computed from the
converged solution.  A stale \(\tilde{\mathbf{J}}\) therefore changes only the
convergence rate, not the discretisation.  Re-evaluating the dense
finite-difference Jacobian at every restart costs \(n_\text{ode}\) right-hand-side
evaluations and dominated the cost of a Brownian node
(70–85 % for four pili), so the last exact Jacobian is re-used
(`LaggedJacobian.m`): refreshed when `ode15s` asks for \(\mathbf{J}\) a second time
inside the same call (Newton failure), after an Euler-basis rotation, and when it
is `cfg.jacobian_max_age` nodes old.  For the four-pilus validation case
(N_body = 200, 5 segments/µm, stiffness \(|\lambda|_\max\approx9\times10^{7}\) in
units of \(T_0^{-1}\)) the spectral radius of the contraction matrix stayed
\(\le0.17\) for a Jacobian up to 64 nodes old at the actual step sizes
(\(h\le1.7\times10^{-3}\)); same-seed trajectories agree with the fresh-Jacobian
solution to \(\sim10^{-5}\) relative.  `cfg.jacobian_reuse=false` restores the
8.5.0 behaviour bit-for-bit.

### 10.4 Thermal fluctuations of the pili (v9.0.0)

With `brownian.pili_thermal = true` (`cfg.enable_pili_brown`) the slowest
bending modes of the pili receive thermal forces of their own.  By default
these are the first and second bending order of every pilus, two
polarisations each (`brownian.pili_mode_orders = 2`).  Twist and all higher
bending orders stay deterministic.  The body-only scheme of §10.1–10.2 is
unchanged and remains the default.

**Thermal modes** (`init_pili_brownian_modes`, once per run, at the
stress-free initial state).  Let \(\mathbf{x}\) collect the deviations of the
material curvatures and of the twist from their intrinsic values at the
interior joints of all pili (`pili_bending_coords`).  The elastic energy of
the discrete Kirchhoff rod is exactly quadratic in these coordinates,

```math
E = \tfrac12\,\mathbf{x}^{\mathsf T}\mathbf{K}\,\mathbf{x},
\qquad
\mathbf{K} = \operatorname{diag}(w_K w_E),
```

with \(w_K = (1, 1, 1/(1+\sigma))\) and \(w_E = 1/(N\ell)\).  Probing the
coupled system with a unit generalised force on each coordinate gives the
curvature mobility, \(\dot{\mathbf{x}} = \mathbf{M}_x\mathbf{f}\); the body and
all other joints are force-free in each probe, so \(\mathbf{M}_x\) contains the
hydrodynamic coupling between filaments and with the moving body.  Free
relaxation is \(\dot{\mathbf{x}} = -\mathbf{M}_x\mathbf{K}\mathbf{x}\), and with the
symmetric part \(\mathbf{M}_s\)

```math
\mathbf{K}^{1/2}\mathbf{M}_s\mathbf{K}^{1/2}\,\mathbf{u}_j = \lambda_j\,\mathbf{u}_j,
\qquad
a_j = \mathbf{u}_j^{\mathsf T}\mathbf{K}^{1/2}\mathbf{x},
\qquad
E = \tfrac12\sum_j a_j^2 .
```

The \(n = 2\,n_o M\) slowest bending-dominated modes are the thermal modes
(\(n_o\) bending orders, \(M\) pili).  They are modes of the whole cell: for
several pili of equal length the same bending order of different pili is
hybridised by the hydrodynamic coupling.  In equilibrium every mode holds
\(k_BT/2\), i.e. \(\langle a_j^2\rangle = k_BT/(F_0L_0)\).  The mode patterns
are stored per joint in the material frame, so they follow the pili and do
not depend on the Euler basis.

All numbers in this section are for the cell of
`configs/config_example.json`: capsule with \(L_0 = 1.25\) µm and radius
0.4 µm, \(E = 3.279\times10^{8}\) Pa, \(r_{\mathrm{pili}} = 3\) nm, hence
\(EI = 2.09\times10^{-26}\) N m², \(T_0 = 2.94\) s and
\(k_BT/(F_0L_0) = 0.2425\) at 293.15 K, in water (\(\mu = 10^{-3}\) Pa s).
Relaxation times scale as \(\mu/EI\) and roughly as the fourth power of the
filament length.

| Cell (3 µm filaments, 30 segments) | Order 1 | Order 2 | Slowest mode without noise |
| --- | --- | --- | --- |
| Capsule + 1 filament | 0.210 s | 13.4 ms | 2.14 ms |
| Capsule + 4 filaments | 0.075–0.62 s | 9.0–16.9 ms | 2.30 ms |

**Joint mobility** (`compute_effective_coupled_brownian`, every interval).
The thermal coordinates are
\(\mathbf{y} = (\mathbf{X}_{cm}, \boldsymbol{\theta}_{body}, a_1,\ldots,a_n)\).
The \((6+n)\times(6+n)\) mobility
\(\dot{\mathbf{y}} = \mathbf{M}_{joint}\,(\mathbf{f}_{body}, \mathbf{g})\) is probed at
the current state with six unit body loads and \(n\) unit modal forces.  A
unit modal force \(g_j\) is the moment pattern
\(\sqrt{w_K/w_E}\,\mathbf{u}_j\) on the bending rows of the coupled system.
The matrix is symmetrised and checked for positive definiteness as in §10.1.

Every pilus mode that is not thermalised — all twist modes and all faster
bending modes of the mode analysis above — is held fixed in every probe:
the holding forces \(\boldsymbol{\lambda}\) on those modes are chosen so that
their amplitudes do not change,
\(\mathbf{A}_{hold}^{\mathsf T}\dot{\mathbf{x}} = 0\).  The reason is a separation
of time scales.  The deterministic modes relax within tens of microseconds
(twist) to about 2 ms (third bending order), whereas the thermal modes
live for 9 ms to 0.6 s.  A force on a thermal coordinate that also moves a
fast mode is opposed by the elastic moment of that mode almost at once, so
over the correlation time of the thermal modes the fast modes act as
constraints, and the mobility that governs the thermal coordinates is the
one with the fast modes held (the inverse of the resistance restricted to
the thermal coordinates).  A probe that leaves them force-free returns the
instantaneous mobility instead.  At the straight rest state the two agree
on the modal block, because the modes are eigenvectors there.  On a bent
filament they do not:

- *Twist.*  A material-frame moment spins the segments of a bent filament
  about their own axes.  This costs almost no viscous drag and rotates the
  two curvature components in the material frame.  For the capsule with one
  filament bent to a fifth of its thermal amplitude the free-twist modal
  mobility is 14 to 196 times the bending relaxation rate.
- *Fast bending modes.*  The rest-state mode patterns mix with the fast
  bending modes once the filament is bent.  Along a thermal trajectory of
  the same cell at 293.15 K a probe that holds the twist only overestimates
  the first-order modal mobility by 16 % in the median and by a factor of
  up to 5, and the response of the time integration over 0.2 ms falls short
  of that probe by up to 50 %.  With every non-thermal mode held the probe
  and the integration agree within 1–3 %.

Noise drawn from an inflated mobility is too weak for the dissipation the
integration actually produces (the fluctuation–dissipation balance is
broken) and the thermal modes fall short of equipartition; this is why the
complete hold is used.  The body block of \(\mathbf{M}_{joint}\) is therefore the
body mobility with the non-thermal modes held and the thermal modes free.
It lies between the fully flexible mobility of §10.1, which applies below
the fast relaxation times, and the rigid-shape mobility, which is reached
beyond the slowest thermal relaxation time.

**Sampling** (`sample_brownian_coupled_force`).  With the joint mobility
frozen at the interval start,

```math
\delta\mathbf{Y} = \mathbf{L}\,\boldsymbol{\eta}\sqrt{\Delta t_B},
\qquad
\mathbf{L}\mathbf{L}^{\mathsf T} = 2k_BT\,\mathbf{M}_{joint},
\qquad
\begin{pmatrix}\mathbf{f}_{th}\\ \mathbf{g}\end{pmatrix}
= \mathbf{M}_{joint}^{-1}\,\frac{\delta\mathbf{Y}}{\Delta t_B},
```

with \(6+n\) normal deviates per interval.  The cross blocks of
\(\mathbf{M}_{joint}\) carry the correlation between the body and the
filaments.  As in §10.2 the forces are held for the whole interval and the
Ito drift is generated by the mobility sampled along the trajectory.

**Realisation of the thermal forces** (`pili_thermal_rhs`, `ode_coupled_rhs`
Step 8e).  The modal forces are not applied as unconstrained white-noise
moments (which would wind a bent filament into a helix).  Instead, every
thermal force — the six body components as well as the modal forces — is
accompanied by the exact hydrodynamic load that the pili carry in the
constrained probe motion of that coordinate: the centreline force density
\(\mathbf{f}_c = (\mathbf{A}\mathbf{Q}_{\mathrm{trans}}\,\mathbf{z}_c)_{pili}\)
(stored in the body frame so it co-rotates with the cell) together with the
balancing scalar axial torque density
\(m_c = (\mathbf{A}\mathbf{Q}_{\mathrm{twist}}\,\mathbf{z}_c)\) applied along
each segment's current tangent \(\mathbf{d}_3\) (\(c = 1,\ldots,6+n\)).  Their
combined generalised force on the pilus rows reproduces the constrained probe
right-hand side — the modal moment pattern together with the holding forces of
all non-thermal modes — to machine precision (\(\sim 10^{-15}\)) even on
strongly bent 3-D filaments.  Including the probe's balancing axial torque
density cancels viscous spin drag without exciting twist (reducing twist
energy on bent filaments by roughly two orders of magnitude and restoring
monotone small-\(\Delta t_B\) covariance convergence).  Its resultant on the
six body rows is not applied a second time (rows 1–6 of the load are set to
zero); the modal part exerts no net force or torque on the cell.

**Mode selection for unequal-length pili.**  By default the \(2\,n_o M\)
slowest bending modes are kept (`pili_mode_orders`).  For cells with pili of
unequal lengths (where \(\tau \propto L^4\)), an optional time-scale cutoff
`brownian.pili_tau_cut_s` selects every bending mode with
\(\tau_j \ge \tau_{\mathrm{cut}}\), and `brownian.pili_protect_pairs` expands
the cut across near-degenerate clusters (gap ratio \(< 1.15\)) so a
polarisation pair is never split.

**Drift of the held loads.**  The implicit Ito drift of §10.2 presumes that
the generalised force stays constant over the interval.  A centreline load
that is held in the body frame does not have this property: as the filament
moves, the arms and directors of the moment balance change, and so does the
modal force that the load exerts.  Let \(g_j(\mathbf{P}_k;\mathbf{y})\) be the
force on mode \(j\) exerted at configuration \(\mathbf{y}\) by the load pattern
\(\mathbf{P}_k\) of mode \(k\) built at the interval start.  Expanding the
displacement over one interval to second order and averaging over the
thermal forces, \(\langle F_mF_n\rangle = 2k_BT(\mathbf{M}_{joint}^{-1})_{mn}/\Delta t_B\),
gives

```math
\langle\delta\mathbf{Y}\rangle
= k_BT\,\Delta t_B\left(\nabla_{\mathbf{y}}\!\cdot\mathbf{M}_{joint}
  + \mathbf{M}_{joint}\,\mathbf{c}\right),
\qquad
c_j = \sum_{k=1}^{n}\frac{\partial g_j(\mathbf{P}_k;\mathbf{y})}{\partial a_k}.
```

The first term is the Ito drift of the thermal coordinates.  The second is
an artefact of the load realisation: a spurious generalised force
\(k_BT\,\mathbf{c}\).  For a single filament on the body axis it vanishes at
the straight rest state and grows linearly with the deflection; at 293.15 K
it acts like a stiffness change of about \(+4\,\%\) for the second bending
order and \(-3\,\%\) for the first.  For filaments attached off the axis it
does not vanish at rest: the body moves in the probe motion, so the loads
have a component along the filament, whose moment changes at first order
when the filament deflects.  For the capsule with four filaments
\(c = -0.31\) for the symmetric first-order mode at rest, which would shift
the mean of that mode by 0.15 of its r.m.s. thermal amplitude at 293.15 K.
The body coordinates do not contribute, because the load co-rotates with
the body and its resultant is not applied.  The sampler removes the
artefact by adding \(-k_BT\,\mathbf{c}\) to the modal forces of the interval.
\(\mathbf{c}\) is evaluated at the interval start by central differences along
the kinematic directions of the thermal modes
(\(\mathbf{z}_{probe}\mathbf{M}_{joint}^{-1}\) using the symmetrised,
SPD-repaired \(\mathbf{M}_{joint}\), non-thermal modes held, body at rest);
only the pilus moment-balance rows of the force operator have to be applied at
the \(2n\) displaced states (via the matrix-free \(O(N_k)\) routine
`apply_pili_B_force_rows` inside `compute_effective_coupled_brownian`,
algebraically identical to `build_force_balance`), not the hydrodynamic
mobility.  With this term the stationary distribution of the thermal modes is
\(\exp(-E/k_BT)\) in the amplitudes \(a_j\), i.e. equipartition.

**Brownian interval.**  The scheme is a coarse-grained effective model that
relies on time-scale separation, so \(\Delta t_B\) must sit inside a two-sided
window:

- *Upper bound* (\(\Delta t_B \lesssim \tau_{\mathrm{slow}}/4\)): a force held
  over \(\Delta t_B\) lowers the stationary variance of a mode of relaxation
  rate \(\lambda\) by the factor \((2/x)\tanh(x/2)\), \(x = \lambda\Delta t_B\)
  (0.5 % at \(x = 0.25\), 2 % at \(x = 0.5\)).  Keep \(\Delta t_B\) at or below
  a quarter of the fastest thermal relaxation time, i.e. 0.002 s for the 3 µm
  filaments of the table above (`run_simulation` warns for \(x > 0.5\) and
  rejects \(x > 2.0\) unless overridden).
- *Lower bound* (\(\Delta t_B \gtrsim \tau_{\mathrm{det}}\)): shrinking
  \(\Delta t_B\) well below the slowest non-thermal bending relaxation time
  \(\tau_{\mathrm{det}}\) (2.14–2.30 ms above) violates the adiabatic
  elimination of the non-thermal bending modes (leaving a small residual drift
  from \(\mathbf{M}_{yb}\) even though the balancing axial torque density keeps
  the single-step covariance convergent and twist-free), so the scheme is not
  intended to be verified by taking \(\Delta t_B \to 0\) at fixed
  `pili_mode_orders` (`run_simulation` warns when
  \(\Delta t_B / \tau_{\mathrm{det}} < 0.5\)).  If finer temporal resolution
  is needed, raise `pili_mode_orders` or lower `pili_tau_cut_s` rather than
  only reducing \(\Delta t_B\).

**Body diffusion.**  The table gives the body diffusion coefficients of the
linearised model (exact covariance recursion of the scheme,
\(\Delta t_B = 0.002\) s).  \(\parallel\) and \(\perp\) refer to the long axis of
the body; \(\boldsymbol{\mu}_{flex}\) is the fully flexible body mobility of
§10.1 and \(\boldsymbol{\mu}_{rigid}\) the mobility of the cell with its
filaments frozen in shape.

| | 1 filament: \(D_{t\perp}\) | \(D_{r\perp}\) | 4 filaments: \(D_{t\parallel}\) | \(D_{t\perp}\) | \(D_{r\parallel}\) | \(D_{r\perp}\) |
|---|---|---|---|---|---|---|
| Lag \(\Delta t_B\), \(D / k_BT\mu_{flex}\): body-only noise | 0.97 | 0.87 | 0.91 | 0.95 | 0.64 | 0.88 |
| Lag \(\Delta t_B\), \(D / k_BT\mu_{flex}\): orders 1–2 | 0.98 | 0.89 | 0.93 | 0.96 | 0.66 | 0.90 |

With the pilus modes thermalised, the thermal coordinates form a closed
system that satisfies the fluctuation–dissipation relation: the noise is
drawn from the mobility with which the system responds, and neither the
noise nor the body motion feeds the deterministic modes.  The long-time
diffusion then equals \(k_BT\,\boldsymbol{\mu}_{rigid}\), the value for a cell
whose shape fluctuations average out, for any number of thermal orders.  In
the body-only scheme the filaments receive no noise but still dissipate, so
the long-time diffusion stays below that value — by a factor of 20 for the
spin of the four-filament cell about its long axis.  At the lag of one
Brownian interval the two schemes agree within 3 %.  Both lie below the
fully flexible value because the modes faster than the interval have
relaxed by then — through their elasticity in the body-only scheme, by
construction (held in the probe) in the thermal scheme, where the body block
of \(\mathbf{M}_{joint}\) is 0.90 (one filament, \(D_{r\perp}\)) and 0.70 (four
filaments, \(D_{r\parallel}\)) of the fully flexible mobility.  The crossover from
\(k_BT\,\boldsymbol{\mu}_{flex}\) within those relaxation times (at most about
2 ms) is not resolved.

**Scope.**  The scheme is built for passive, naturally straight filaments
with clamped roots.  `root_coupling = free_torsion` is rejected: the spin of
the filament about its root axis is a coordinate without elastic restoring
moment that is neither thermalised nor held, and the joint mobility loses
its symmetry and definiteness once the filament bends.  Intrinsic-curvature
overrides and active moments are accepted with a warning: the thermal modes
are those of the passive initial state, and the equipartition tests below
do not cover these cases.

**Acceptance (v9.0.0).**  Operator tests at the production resolution
(306 body points, 30 segments per filament), for one and four filaments:
joint-mobility asymmetry \(2.7\times10^{-4}\) and \(1.4\times10^{-3}\); modal
diagonal within 0.2 % of the relaxation rates; response of the right-hand
side to the thermal forces equal to \(\mathbf{M}_{joint}\mathbf{F}\) within
\(3.7\times10^{-3}\); static deflection under a held modal force equal to the
force within \(2.6\times10^{-3}\); relaxation rates measured from the ODE
within 0.2 % of the eigenvalues; invariance under a change of Euler basis to
better than \(10^{-7}\).  On six states of a thermal trajectory (one
filament, 293.15 K) the response of the time integration is 0.97–1.00 of

within 2 %, and the held-load term by itself is recovered with a factor of

## 11. Flow-Field Visualization

[`compute_plot_flowfield.m`](../src/visualization/compute_plot_flowfield.m) reconstructs the end-state geometry, evaluates the flow on the XZ (Y = Y_cm), YZ (X = X_cm) and XY (Z = Z_cm) planes through the body centre, masks body interiors, and exports a 2 x 3 panel figure:

- 3D XZ, YZ and XY plane views (top row).
- 2D XZ, YZ and XY velocity magnitude and normalized direction arrows (bottom row).

Custom bodies use stored triangulation and alpha-shape based interior masking where available.

From v8.7.0, each saved output also stores `results.flow_state`: the full state, the pilus basis, and the Brownian force that produced that output. [`render_flowfield_from_results.m`](../post_processing/render_flowfield_from_results.m) uses those data to draw the final state, selected times, or an animation. ## 12. Walker Scaling Consistency

When the coupled problem is reduced to a single free elastic filament without the body, the nondimensional structure is designed to remain consistent with the Walker-style Kirchhoff-rod formulation:

- The spatial $Q$ matrix has the same role: it maps body-frame or rod-frame generalized rates into translational and angular velocities along the filament.
- The force-balance rows use trapezoidal quadrature weights, while the pilus moment-balance rows use the per-rod length scaling.
- Elastic and active moments are stored in the per-pilus arclength coordinate $s_k\in[0,1]$.

For torsional resistance, the dimensional segment relation is proportional to the local segment length:

```math
\tau_{\mathrm{twist},j}
\sim
c_t\,\Delta s_k\,\dot{\psi}_j,
\qquad
c_t \sim 4\pi\mu r_{\mathrm{pili}}^2.
```

Using the global project scales gives the nondimensional torsional coefficient:

```math
\frac{c_t\,\Delta s_k/T_0}{EI/L_0}
\sim
\frac{\varepsilon^2}{2}\,\Delta \hat{s}_k.
```

The implementation stores each pilus on its own normalized arclength, so the conversion between the global body scale and the per-pilus Walker scale introduces the pilus length ratio $\ell_k = L_{\mathrm{pili},k}/L_0$. Per-pilus slenderness is $\varepsilon_k = \varepsilon/\ell_k = r_{\mathrm{pili}}/L_{\mathrm{pili},k}$ (`build_global_resistance.m`).

```math
\widetilde{\mathbf{A}}_{\mathrm{twist},k}
=
\frac{\ell_k\varepsilon_k^2}{2}
\widehat{\mathbf{A}}_k
=
\frac{\varepsilon^2}{2\ell_k}
\widehat{\mathbf{A}}_k.
```

The two right-hand forms are algebraically equivalent because $\ell_k\varepsilon_k^2 = \varepsilon^2/\ell_k$.

The complementary $\ell_k^3$ factor used in each pilus moment-balance row converts the per-rod moment equations back to the global scale, keeping the assembled system

```math
\mathbf{L}\dot{\mathbf{z}} = \mathbf{R}
```

dimensionally homogeneous.

## 13. Validation Scope

The codebase has been checked against the following model-level invariants:

- Quaternion convention and body orientation kinematics.
- RSM kernel scaling and body-volume consistency.
- RSS recurrence terms and segment matrix symmetry checks.
- Rotlet anti-symmetry and recurrence behavior.
- Walker-style Euler-angle `Q` matrix and moment-balance scaling.
- Clamped and free-torsion root boundary constraints.
- Multi-pilus state layout, geometry reconstruction, and matrix dimensions.
- Full-coupled effective body mobility and body-only Brownian Cholesky positive-definiteness checks.
- Weighted translation/twist reciprocity and symmetric power dissipation.
- Scale-independent linear-solve backward residuals, selected-state `rcond`,
  finite-value checks, and the conditioning of the exact multi-motor
  torque-speed linear solve.
- Output units for MAT, CSV, figure, and log files.

Backward residuals above \(10^{-10}\) warn and values above \(10^{-6}\)
abort.  Coupled-matrix `rcond` below `1e-10` or `1e-14` warns and is
recorded; a hard abort requires the joint gate of residual \(>10^{-6}\)
and `rcond<1e-14`.  Measured extrema and the fixed thresholds are saved
in `results.diagnostics`.

Detailed bug-fix history belongs in [`../CHANGELOG.md`](../CHANGELOG.md), not in this theory document.

## 14. Measured-gait active moment

The biflagellate swimmer in [`../chlamydomonas/`](../chlamydomonas/) does not use a prescribed traveling-wave moment. A measured planar gait is imposed as a known state and rate. The rigid-body velocity comes from the force and torque rows of the same coupled linear system as the forward solver (§6). The rod rows then give the internal active moment that makes that motion an exact solution of the discrete model,

\[
\mathbf{M}_{\mathrm{act}} = \boldsymbol{\kappa}_{\mathrm{dev}} - \mathrm{lin\_sys}\,\dot{\mathbf{z}}.
\]

Only the bending component about \(\mathbf{d}_2\) is kept. `chlamy_inverse_moment` stores it as a Fourier series in time at each node. Closed-loop runs use the two-harmonic analytic fit from `chlamy_fit_moment`; flagellum 2 is the mirror image of flagellum 1. A beat-plane tilt rotates the moment about each flagellum's own root tangent, and the amplitude, phase and frequency ratio may differ between the two flagella; an optional proximal 1ω+2ω out-of-plane bending envelope (`chlamy_make_perp_envelope`) acts along \(\mathbf{d}_3 \times \hat{\mathbf{n}}\) with strictly zero parasitic twist moment. Settling and motor-driven cases do not take this path.
