## 1. Physical Problem

The simulator models a bacterial body with flexible pili or flagella settling in a Stokes-flow environment:

- **Body:** rigid capsule, sphere-like body, or imported custom 3D point cloud.
- **Pili / flagella:** one or more inextensible Kirchhoff elastic rods.
- **Fluid:** zero-Reynolds-number Stokes flow.
- **Coupling:** hydrodynamic interactions between all body and pili points are retained through a global mobility solve.

The default parametric body is a capsule with two hemispherical caps and a cylindrical midsection. In custom geometry mode, both the body and pili are imported from user-provided point clouds; mixing custom and parametric geometry in either direction is rejected by `validate_simulation_params.m` when the mixed fields reach the validator (inline or programmatic `cfg`, or JSON loaded into `cfg` and passed through `run_simulation.m`). Note: in JSON parametric mode, `load_sim_config.m` does **not** read a top-level `custom_geometry` block into `cfg`, so such stray keys are silently ignored at load time rather than validated—remove them from the JSON file or switch to `geometry_mode: "custom"`.

An imported pilus curve is converted once to a canonical equal-chord polygon:
consecutive duplicates are removed, a PCHIP parameter curve is formed, and
nested scalar root solves choose monotonically increasing parameters with a
common endpoint-to-endpoint chord length.  Reference nodes, all material
directors, and intrinsic curvature are derived from that same polygon.
Initial body orientation then applies one rigid rotation to every reference
director before Euler angles are recovered, preserving objectivity for curved
stress-free rods.  All pili share the global \(E\) and \(r_{\mathrm{pili}}\);
there is no per-pilus stiffness parameter.

Parametric pili are generated by `pili_type_building.m` as a template along
\(+x\) (bending plane \(xy\)) and placed on one of 14 body attachment sites by
`pili_building.m`. Since v8.3.0 every site map is a proper rotation
\(R=[\mathbf{c}_1,\mathbf{c}_2,\mathbf{c}_1\times\mathbf{c}_2]\) (outward
direction \(\mathbf{c}_1\), bending direction \(\mathbf{c}_2\)) followed by a
translation, and the optional deflection matrices \(R_z(\theta)\), \(R_x(\gamma)\)
are right-handed. Earlier versions used coordinate swaps with \(\det=-1\) at
sites 1, 2, 5, 7, 10, 11, 14 and a left-handed \(R_x\), which mirrored chiral
templates (conical spiral) and the twist sense of `deflection_x`; planar
templates without `deflection_x` are placed identically in both versions.

## 2. Main Methods

| Component | Method | Main source |
| --- | --- | --- |
| Body hydrodynamics | Regularized Stokeslet Method (RSM) on body surface points | Cortez et al. (2005) |
| Pili hydrodynamics | Regularized Stokeslet Segments (RSS) with exact segment integration | Cortez (2018) |
| Pili twist-flow coupling | Regularized rotlet segments | Cortez (2018) |
| Pili elasticity | Kirchhoff elastic rod with Euler-angle directors | Walker (2020) |
| Body orientation | Quaternion kinematics | Project implementation |
| Time integration | MATLAB `ode15s` with event-driven segmenting | Project implementation |

The key numerical advantage is that RSS integrates the regularized Stokeslet kernel along each straight pilus segment exactly. This separates segment length from regularization radius, allowing roughly `10` segments per micrometer for typical pili while keeping hydrodynamic interactions resolved.

## 3. Nondimensionalization

The body semi-major axis is used as the reference length:

| Quantity | Symbol | Definition |
| --- | --- | --- |
| Length | $L_0$ | body `major_axis` (parametric); `L_0_override` or body-derived suggestion (custom) |
| Bending stiffness | $EI$ | $E\pi r_{\mathrm{pili}}^4/4$ |
| Time | $T_0$ | $8\pi\mu L_0^4/EI$ |
| Velocity | $U_0$ | $L_0/T_0$ |
| Force | $F_0$ | $EI/L_0^2$ |

Important dimensionless parameters are:

- Elastic-gravity number: $E_g = F_{\mathrm{sink}}L_0^2/EI$.
- Pili slenderness: $\varepsilon = r_{\mathrm{pili}}/L_0$.
- Poisson ratio: $\sigma$, supplied by the user.

The sinking force (dimensional) is

```math
F_{\mathrm{sink}} = (\rho_{\mathrm{bac}} - \rho_{\mathrm{fluid}})\, V_{\mathrm{body}}\, g,
```

where $V_{\mathrm{body}}$ is the capsule volume in parametric mode or the alpha-shape volume in custom mode. Gravity enters the ODE right-hand side as $\mathbf{R}_{1:3} = -E_g\,\hat{\mathbf{g}}$ with $\hat{\mathbf{g}} = [0,0,-1]^\mathsf{T}$.

The root–body gap (dimensional) is

```math
\mathrm{dis} = 1.1\,(\varepsilon_{\mathrm{body}} + \varepsilon_{\mathrm{pili}})\,L_0,
```

passed to `pili_building` / `custom_pili_building` to keep regularized kernels separated at the pilus root.

Additional model inputs use the same reference scales:

- Background flow velocity: $\mathbf{u}_{\mathrm{bg}}^\ast = \mathbf{u}_{\mathrm{bg}}/U_0$.
- Integrated active moments: $\mathbf{M}^\ast = \mathbf{M}_{\mathrm{phys}}L_{\mathrm{pili}}/EI$.
- Intrinsic curvature: stored on the same nondimensional arclength scale as the Euler-angle curvature fields.

## 4. State Vector and Geometry

The full state contains body position, body orientation, and each pilus rod state:

```math
\mathbf{Z} =
\left[
\mathbf{X}_{\mathrm{cm}},
\mathbf{q},
\boldsymbol{\theta}_1,
\boldsymbol{\phi}_1,
\boldsymbol{\psi}_1,
\ldots,
\boldsymbol{\theta}_M,
\boldsymbol{\phi}_M,
\boldsymbol{\psi}_M
\right].
```

The body quaternion $\mathbf{q}$ represents the body-to-lab rotation and is advanced with:

```math
\frac{d\mathbf{q}}{dt}
= \frac{1}{2}
\begin{bmatrix}
0 \\
\boldsymbol{\Omega}
\end{bmatrix}
\otimes \mathbf{q}.
```

Here $\boldsymbol{\Omega}$ is the **body angular velocity in the lab frame**, taken from `z_dot(4:6)` of the coupled solve (`quat_kinematics.m`).

For each pilus, Euler angles define the material directors `(d1, d2, d3)`, where `d3` is the segment tangent. [`reconstruct_geometry.m`](../src/geometry/reconstruct_geometry.m) maps `Z` to lab-frame body points, pilus nodes, directors, and auxiliary geometry used by the hydrodynamic solve.

## 5. Hydrodynamics

### 5.1 Body RSM

Body surface forces are represented by the Cortez regularized Stokeslet kernel:

```math
\mathbf{S}^{\varepsilon}(\mathbf{r})
=
\frac{
\left(\lVert\mathbf{r}\rVert^2 + 2\varepsilon^2\right)\mathbf{I}
+ \mathbf{r}\mathbf{r}^{\mathsf{T}}
}{
\left(\lVert\mathbf{r}\rVert^2 + \varepsilon^2\right)^{3/2}
}.
```

The body regularization length defaults to:

```math
\varepsilon_{\mathrm{body}} = h_{\mathrm{mean}}/2.6667.
```

where `h_mean` is the mean nearest-neighbor spacing of the body surface points in nondimensional units. This default was calibrated by the `N_body x eps_body` Stokes-sphere sweep and can be overridden by `body.eps_body` in JSON or `cfg.eps_body` in MATLAB.

### 5.2 Pili RSS

For a straight segment from $\mathbf{y}_0$ to $\mathbf{y}_1$, RSS evaluates the velocity contribution of a linearly varying force density:

```math
\mathbf{u}(\mathbf{x})
=
\mathbf{M}_1\mathbf{f}_0
+ \mathbf{M}_2\mathbf{f}_1.
```

The matrices `M1` and `M2` include exact segment integration weights. No additional trapezoidal length factor is applied to the RSS segment columns. The required `T_{n,q}` integrals are evaluated by the Cortez (2018) recurrence.

For pili, the regularization length is physical:

```math
\varepsilon_{\mathrm{pili}} = r_{\mathrm{pili}}/L_0.
```

Unlike body RSM regularization, this value represents the finite radius of the pilus and is not a numerical parameter to send toward zero.

### 5.3 Rotlet Segments

Twist-induced flow is included through regularized rotlet segments:

```math
\mathbf{u}(\mathbf{x})
=
-L
\left(
c_a[\mathbf{x}_0]_{\times}
+ c_b[\mathbf{v}]_{\times}
\right)
\boldsymbol{\tau}.
```

where `tau` is the segment torque density. The implementation stores the Cortez (2018) full-curl rotlet segment kernel as `M_rotlet`; when this block is coupled reciprocally to Stokeslet translation, the physical standard-rotlet convention is enforced through the factor `0.5*M_rotlet`.

## 6. Coupled Linear System

At each ODE right-hand-side call, the simulator assembles:

```math
\mathbf{L}\dot{\mathbf{z}} = \mathbf{R},
```

with:

```math
\mathbf{L} = -\mathbf{B}\mathbf{A}\mathbf{Q}.
```

Since v7.6.0, axial twist no longer uses a local RFT torsional resistance. The translational and axial-spin unknowns are coupled through the grand mobility:

```math
\begin{bmatrix}
\mathbf{u} \\
\omega_\parallel
\end{bmatrix}
=
\begin{bmatrix}
\mathbf{M}_{\mathrm{weighted}} & \mathbf{C}_{\mathrm{forward}} \\
\mathbf{C}_{\mathrm{reverse}} & \mathbf{M}_{\mathrm{twist}}
\end{bmatrix}
\begin{bmatrix}
\mathbf{f} \\
\mathbf{m}
\end{bmatrix},
```

where `M_twist` is the non-local segment-integral axial rotation mobility and

```math
\mathbf{C}_{\mathrm{forward}}
=
\tfrac{1}{2}\mathbf{M}_{\mathrm{rotlet}}\mathbf{D}_{\mathrm{twist}},
\qquad
\mathbf{C}_{\mathrm{reverse}}
=
\mathbf{W}_m^{-1}\mathbf{C}_{\mathrm{forward}}^{\mathsf T}\mathbf{W}_f.
```

Here \(\mathbf{W}_f\) repeats the body/RSS quadrature weight for each
Cartesian force component and
\(\mathbf{W}_m=\operatorname{diag}(L_s)\) uses the actual segment lengths.
Thus
\(\mathbf{W}_f\mathbf{C}_{\mathrm{forward}}
=\mathbf{C}_{\mathrm{reverse}}^{\mathsf T}\mathbf{W}_m\), which is the
discrete virtual-power form of Lorentz reciprocity.  An ordinary transpose
would be correct only when both measures were identical.  The `1/2` factor
converts Cortez's full-curl rotlet segment kernel to the physical
standard-rotlet convention. The code applies the inverse action by Schur
complement:

```math
\mathbf{S}_{\mathrm{twist}}
=
\mathbf{M}_{\mathrm{twist}}
-
\mathbf{C}_{\mathrm{reverse}}
\mathbf{M}_{\mathrm{weighted}}^{-1}
\mathbf{C}_{\mathrm{forward}},
```

so the same coupled operator is used in the main linear system and in background-flow corrections.

`M_twist` maps torque density to angular velocity and is therefore also
self-adjoint in the line measure:
\(\mathbf{W}_m\mathbf{M}_{\mathrm{twist}}
=\mathbf{M}_{\mathrm{twist}}^{\mathsf T}\mathbf{W}_m\).
The implementation enforces this relation using each segment's endpoint
distance; it does not assume equal segment lengths across different pili.

The main blocks are:

- `Q_global`: maps generalized rates to body and pilus node velocities.
- `M_weighted`: full translational hydrodynamic mobility matrix, including body RSM and pili RSS blocks.
- `M_twist`: non-local axial twist mobility.
- `D_twist`: embeds scalar axial torque density into segment-aligned 3D rotlet vectors.
- `C_forward`, `C_reverse`: weighted-adjoint translation/twist coupling blocks with physical standard-rotlet scaling.
- `B_global`: maps distributed forces and line-integrated torques into global force, moment, and pilus moment-balance equations.
- `R`: gravitational force, elastic moments, active moments, background-flow corrections, and motor torque terms.

**Global angular-momentum balance (since v7.6.0).** The total hydrodynamic torque the swimmer exerts on the fluid is the sum of the Stokeslet moment and the line-integrated net rotlet torque,

```math
\mathbf{T} = \sum_i \mathbf{r}_i \times \mathbf{f}_i + \sum_s L_s \mathbf{m}_s,
```

because `m_s` is a torque density on segment `s`. Therefore the moment rows of `B_global` include both `sum(r x f)` and `sum(L_s m_s)`. This makes a force/torque-free swimmer exactly torque-free and yields the correct body counter-rotation for motor-driven or spinning pili.

Solves use MATLAB decomposition / LU factorization rather than explicit matrix inversion.

## 7. Elastic Rod Moments

Pili are treated as Kirchhoff rods. The Darboux vector is:

```math
\mathbf{U}
=
\kappa_1\mathbf{d}_1
+ \kappa_2\mathbf{d}_2
+ \kappa_3\mathbf{d}_3,
```

with director evolution:

```math
\mathbf{d}_{\alpha}' = \mathbf{U}\times\mathbf{d}_{\alpha}.
```

The curvature components used in [`compute_pili_elastic_moments.m`](../src/physics/compute_pili_elastic_moments.m) are:

```math
\kappa_1
=
\mathbf{d}_3\cdot\mathbf{d}_2'
- \kappa_{1,0},
```

```math
\kappa_2
=
\mathbf{d}_1\cdot\mathbf{d}_3'
- \kappa_{2,0},
```

```math
\kappa_3
=
\frac{
\mathbf{d}_2\cdot\mathbf{d}_1'
- \kappa_{3,0}
}{1+\sigma}.
```

Intrinsic curvature can be configured per pilus as `frozen`, `zero`, `constant`, or `helix`. Active moments can be disabled, prescribed as a traveling wave, or supplied by custom configuration.

### Discrete curvature stencil (v8.3.0)

Directors are stored per segment (segment \(i\) spans \(s\in[(i-1)\,\Delta s,\ i\,\Delta s]\), \(\Delta s = 1/N\)) while the moment balance is written at nodes. The shared operator [`compute_pili_curvature.m`](../src/physics/compute_pili_curvature.m) evaluates the three components at node \(i\) as

```math
\kappa_1(s_i) = \mathbf{d}_3^{(i)}\cdot\frac{\mathbf{d}_{2,i}-\mathbf{d}_{2,i-1}}{\Delta s},\qquad
\kappa_2(s_i) = \mathbf{d}_1^{(i)}\cdot\frac{\mathbf{d}_{3,i}-\mathbf{d}_{3,i-1}}{\Delta s},\qquad
\kappa_3(s_i) = \mathbf{d}_2^{(i)}\cdot\frac{\mathbf{d}_{1,i}-\mathbf{d}_{1,i-1}}{\Delta s},
```

where \(\mathbf{d}_{\alpha,i}\) are the **segment** directors and \(\mathbf{d}_\alpha^{(i)}\) is the **nodal** director obtained by the SVD polar mean of the two segment frames adjacent to node \(i\) ([`compute_node_directors.m`](../src/physics/compute_node_directors.m)). Segments \(i-1\) and \(i\) are centred at \(s_i \mp \Delta s/2\), so the difference quotient is a central estimate of \(\mathbf{d}_\alpha'(s_i)\) collocated with the nodal director it is projected onto; the scheme is therefore \(O(\Delta s^2)\). The pre-8.3.0 implementation differenced the nodal directors themselves, which centred the derivative at \(s_i - \Delta s/2\) and reduced the projection to \(O(\Delta s)\) (verified numerically on an analytic constant-Darboux-vector frame: observed orders 2.00 vs 0.98). Node 1 borrows the node-2 stencil and is subsequently replaced by the root boundary condition; node \(N+1\) is moment-free and unused. The intrinsic curvature `kb0` in `init_coupled_params.m` is produced by the same operator, so a `frozen` pilus is an exact zero-moment equilibrium at \(t=0\) (residual \(\sim 10^{-13}\)).

## 8. Root Coupling and Motor Torque

Each pilus root supports two boundary modes:

- `clamped`: root bending and twist angles are locked to the body frame.
- `free_torsion`: root bending angles remain locked, but the root twist angle `psi_1` evolves dynamically.

In `free_torsion`, the root `d3` moment row is the axial moment balance of the whole filament about the root; its right-hand side is the boundary torque transmitted by the body (the motor torque, or zero for a frictionless bearing) — see "Root twist row" below. As of v7.3.0, no explicit motor reaction term is added to `R_global(4:6)`. Those rows are the angular-momentum balance for the entire coupled body-pilus hydrodynamic system, so a motor torque exchanged internally between body and pilus cancels in the system sum. The body angular response is still present, but it emerges implicitly from the coupled Stokes solve and the root kinematic constraints.

### Motor torque-speed law (v8.2.0)

The effective motor torque follows the linear torque-speed relation of the bacterial flagellar motor (Berg & Turner 1993; Berg 2003), written in the rotor speed relative to the cell body:

$$\tau_{\mathrm{eff}} = \tau_{\mathrm{motor}}\left(1 - \frac{\omega_{\mathrm{rel}}}{\omega_{\max}}\right),\qquad
\omega_{\mathrm{rel}} = \operatorname{sign}(\tau_{\mathrm{motor}})\,\Big[\big(\dot\psi_1 + \cos\theta_1\,\dot\phi_1\big) - \boldsymbol{\Omega}_{\mathrm{body}}\cdot\mathbf{d}_3^{(1)}\Big].$$

$\dot\psi_1 + \cos\theta_1\dot\phi_1$ is the full axial angular velocity of segment 1 in the Walker Euler-angle kinematics (the same expression that defines the twist-rate rows of the linear system); subtracting $\boldsymbol{\Omega}_{\mathrm{body}}\cdot\mathbf{d}_3^{(1)}$ makes the speed frame-independent and equal to the rotor-stator relative rotation that the motor actually senses. The sign factor measures the speed in the driving direction, so one law serves CW and CCW motors. The law is asymmetric: forced backward rotation ($\omega_{\mathrm{rel}}<0$) raises the torque above stall, and $\omega_{\mathrm{rel}}>\omega_{\max}$ gives a braking torque. Since $z_{\dot{}}$ is affine in the motor torques, $\omega_{\mathrm{rel}} = a + B\tau$ with $a$ the motor-free solution and $B$ the response to unit torques (both from one factorisation of `lin_sys`), and the self-consistent torques solve the small linear system $(I + \operatorname{diag}(|\tau_{\mathrm{motor}}|/\omega_{\max})B)\,\tau = \tau_{\mathrm{motor}} - \operatorname{diag}(|\tau_{\mathrm{motor}}|/\omega_{\max})\,a$ exactly.

Sign convention: because `R_global` stores the negative of the applied generalised force, the motor torque enters its $\psi_1$ row as $-\tau$; a positive `torque_pN_nm` therefore drives the rotor in the right-handed sense about the outward root tangent $\mathbf{d}_3$ (counter-clockwise viewed from the filament tip toward the cell).

### Root twist row for `free_torsion` (v8.4.0)

Row $i$ of the pilus moment balance is the balance of the rod portion $[s_i, 1]$ about node $i$:

```math
\mathbf{M}(s_i) + \int_{s_i}^{1}\big(\mathbf{x}-\mathbf{x}_i\big)\times\mathbf{f}\,\mathrm{d}s + \int_{s_i}^{1}\mathbf{m}\,\mathrm{d}s = \mathbf{0},
```

where $\mathbf{M}(s_i)$ is the internal moment exerted by $[0,s_i)$ on $[s_i,1]$. For an interior node this is the Kirchhoff moment $EI(\kappa_1\mathbf{d}_1+\kappa_2\mathbf{d}_2)+GJ\kappa_3\mathbf{d}_3$ plus the integrated active moment. At the root node, $[0,s_1)$ is the cell body, so $\mathbf{M}(0)$ is the torque the body applies to the rod: an unknown reaction for `clamped` (the three rows become kinematic constraints) and, for `free_torsion`, $\mathbf{M}(0)\cdot\mathbf{d}_3 = \tau_{\mathrm{eff}}$ (zero for a frictionless bearing). The discrete $\kappa_3$ available at node 1 is evaluated between segments 1 and 2 and is already the internal moment used by the node-2 balance. Before v8.4.0 it was nevertheless also added to the root row; subtracting the node-2 row shows that the motor torque was then balanced by the hydrodynamic torque on segment 1 alone, so the steady rotor speed of a straight filament scaled as $N$ times the physical value (verified: $N=10$ gives $8.47\times10^4$ vs. $8.84\times10^3$ rad/s after the fix; the twist profile is linear from node 2 to the tip with $GJ\kappa_3(s_2)=\tau_{\mathrm{eff}}(1-1/N)$). The root rows of `compute_pili_elastic_moments.m` and `coupled_active_moment.m` are now zero for both coupling modes, and the `free_torsion` $\psi_1$ row carries only the boundary torque. Consequences: a free bearing without a motor enforces zero net axial hydrodynamic torque on the filament (a purely internal twist wave cannot spin it), and with a motor the steady speed of a straight filament is $\omega=\tau_{\mathrm{eff}}/(\xi_t L)$ with $\xi_t = 2\pi\mu\epsilon^2$ for the regularised-rotlet-segment line of the Cortez (2018) 7/2 blob (half the no-slip-cylinder value $4\pi\mu a^2$ at $a=\epsilon$; the simulator reproduces this coefficient to $<10^{-3}$).

## 9. Background Flow

Background flow is evaluated as a prescribed steady velocity field and incorporated through the hydrodynamic correction:

```math
\mathbf{R}
\leftarrow
\mathbf{R}
- \mathbf{B}\mathbf{A}^{-1}\mathbf{u}_{\mathrm{bg}}.
```

Supported flow types are:

- `off`: no background flow.
- `uniform`: constant velocity with user-defined direction.
- `shear_z`: finite-thickness clipped shear layer with user-defined flow direction, shear axis, and thickness.  Incompressibility requires the normalized flow and shear directions to be orthogonal; validation rejects `abs(dot)>1e-12`.

Inside the unclipped shear layer,
\(\mathbf{u}=U\,\hat{\mathbf d}(\hat{\mathbf s}\cdot\mathbf{x})/H\),
so \(\nabla\cdot\mathbf{u}=(U/H)\hat{\mathbf d}\cdot\hat{\mathbf s}\).
Orthogonality is therefore a mass-conservation condition, not merely a
preferred coordinate convention.

## 10. Brownian Dynamics

When Brownian motion is enabled, the observation window is divided into
Brownian intervals of length `dt_B` (the last one uses the actual remainder).
Since v8.5.0 the body-only thermal motion is realised as a **constant
generalised thermal force** acting on the body throughout each interval
("force realisation"), rather than as a displacement kick applied between
deterministic segments:

1. At the start of each interval, compute the effective body mobility by
   probing the full deterministic body-pili system (Section 10.1).
2. Draw the frozen-mobility Euler–Maruyama increment \(\delta\mathbf{U}\)
   and convert it into the generalised force \(\mathbf{f}_{\mathrm{th}}\)
   that would produce it on the frozen system (Section 10.2).
3. Integrate the coupled system with `ode15s` over the interval with
   \(\mathbf{f}_{\mathrm{th}}\) added to the six body rows of the right-hand
   side (`ode_coupled_rhs` Step 8a); the pili respond to the body's thermal
   motion through the same hydrodynamic and elastic coupling as to gravity
   or a motor torque.

### 10.1 Effective body mobility

The effective mobility is computed by probing the coupled linear system with six unit generalized body loads:

```math
\mathbf{M}_{\mathrm{eff}}^{\ast}(:,i)
=
\left(\mathbf{L}^{-1}(-\mathbf{e}_i)\right)_{1:6},
\qquad i=1,\ldots,6.
```

The symmetric positive-definite check and any round-off-scale spectral repair
are performed on the dimensionless mobility.  A materially negative
eigenvalue is an assembly error rather than something to clamp.  The repaired
matrix is then converted to physical units by a congruence transformation:

```math
\mathbf{D}_{\mathrm{eff}}
=
k_B T\,\mathbf{M}_{\mathrm{eff,dim}},
```

```math
\mathbf{L}_{\mathrm{eff}}
\mathbf{L}_{\mathrm{eff}}^{\mathsf{T}}
=
2\mathbf{D}_{\mathrm{eff}},
```

```math
\delta\mathbf{U}
=
\mathbf{L}_{\mathrm{eff}}
\boldsymbol{\eta}
\sqrt{\Delta t_B},
\qquad
\boldsymbol{\eta}\sim\mathcal{N}(\mathbf{0},\mathbf{I}_6).
```

Brownian samples come from a run-local random stream and are independent of
geometry-cache creation; exactly six normal deviates are consumed per
interval.

### 10.2 Force realisation of the increment (v8.5.0)

With the effective mobility frozen at the interval start, the generalised
force that produces exactly \(\delta\mathbf{U}\) over \(\Delta t_B\) is

```math
\mathbf{f}_{\mathrm{th}}
=
\mathbf{M}_{\mathrm{eff}}^{-1}\,
\frac{\delta\mathbf{U}}{\Delta t_B},
```

evaluated in the dimensionless generalised units of the coupled system
(rows 1–3 in \(F_0\), rows 4–6 in \(F_0 L_0\); `sample_brownian_body_force`).
It enters the right-hand side with the same sign convention as gravity,
\(\mathbf{R}(1{:}6) \leftarrow \mathbf{R}(1{:}6) - \mathbf{f}_{\mathrm{th}}\),
and is held constant while `ode15s` integrates the interval.  The realised
body increment is therefore \(\int \mathbf{M}_{\mathrm{eff}}(t)\,\mathbf{f}_{\mathrm{th}}\,dt\)
along the actual coupled trajectory rather than the frozen-mobility value.

**Why the pilus root no longer kinks.**  Before v8.5.0 the body pose was
displaced instantaneously at each node and the first pilus segment was then
re-projected onto the moved body while segments \(2\ldots N\) kept their
old orientation.  Each kick therefore injected a curvature discontinuity
between segments 1 and 2 whose amplitude scaled with
\(|\delta\boldsymbol{\Theta}|/\ell\); with \(\ell \ll 1\) this excited
high-wavenumber elastic modes that relaxed on the stiff time scale
\(\ell^4\) and forced `ode15s` into very small steps.  With force
realisation, the body moves continuously and the pili follow through the
coupled solve; the root constraint is never violated, so no spurious mode is
excited.

**Implicit Ito drift.**  The overdamped SDE with configuration-dependent
mobility requires the drift \(k_B T\,\nabla\!\cdot\!\mathbf{M}\) in the Ito
convention.  Expanding the coupled ODE over one interval,

```math
\delta\mathbf{U}_{\mathrm{real}}
=
\mathbf{M}_n\mathbf{f}_{\mathrm{th}}\Delta t_B
+ \tfrac12\,(\partial_j\mathbf{M})\,(\mathbf{M}_n\mathbf{f}_{\mathrm{th}})_j\,\mathbf{f}_{\mathrm{th}}\,\Delta t_B^2
+ \mathcal{O}(\Delta t_B^{3/2}),
```

and using
\(\mathbb{E}[\mathbf{f}_{\mathrm{th}}\mathbf{f}_{\mathrm{th}}^{\mathsf T}]\,\Delta t_B = 2k_BT\,\mathbf{M}_n^{-1}\)
gives

```math
\mathbb{E}\big[\delta\mathbf{U}_{\mathrm{real}}\big]
=
k_B T\,\nabla\!\cdot\!\mathbf{M}\,\Delta t_B
+ \mathcal{O}(\Delta t_B^{3/2}),
\qquad
\operatorname{Cov}\big[\delta\mathbf{U}_{\mathrm{real}}\big]
=
2k_BT\,\mathbf{M}_n\,\Delta t_B
+ \mathcal{O}(\Delta t_B^{3/2}).
```

The mobility gradient sampled along the trajectory thus generates the Ito
drift automatically: the scheme is a consistent weak first-order integrator
of the body-only Ito SDE, and the explicit finite-difference
\(k_B T\,\nabla\!\cdot\!\mathbf{M}\) correction used in v7.5.0–v8.4.0 (twelve
additional coupled solves per node) is no longer applied — adding it again
would double count the drift.

For the present wall-free model the point is largely formal: in an unbounded
fluid the effective mobility depends on the body pose only through the
orientation, \(\mathbf{M}_{\mathrm{eff}} = \mathbf{R}\,\mathbf{M}_{\mathrm{shape}}\,\mathbf{R}^{\mathsf T}\),
and the divergence of such a tensor with respect to the six body pose
coordinates vanishes identically (translations do not enter; the rotational
divergence \(\partial_{\theta_k}(\mathbf{R}\mathbf{M}\mathbf{R}^{\mathsf T})_{ik}\)
cancels for symmetric \(\mathbf{M}\)).  The body-pose Ito drift is therefore
zero for both the old and the new scheme, and the implicit-drift property
only becomes quantitatively relevant if boundaries or other pose-dependent
mobilities are added.  The change of \(\mathbf{M}_{\mathrm{eff}}\) through
the pili deforming under the thermal force during an interval is part of
the coupled dynamics, not a drift correction.

**Scope of the Brownian approximation.**  The hydrodynamic drag of every
pilus affects the probed 6 x 6 body mobility, but pilus internal Euler-angle
coordinates receive no stochastic forcing.  Those modes evolve only under
deterministic elasticity, hydrodynamics, active moments, motor torques, and
the thermal force transmitted from the body.  Consequently this model is
suitable for body translation/orientation diffusion when internal pilus
thermal fluctuations are neglected; it is not a full coupled equilibrium
process and cannot reproduce pilus-mode equipartition.

**Known approximation — deterministic/stochastic operator consistency.**

The deterministic solve uses the raw hydrodynamic mobility `M_weighted`, which is structurally non-symmetric when `eps_body != eps_pili`: the body RSM block (source `eps = eps_body`) and the pili RSS block (source `eps = eps_pili`) apply different regularisation lengths to the same body–pili pair of entries, so Lorentz reciprocity is not exactly satisfied in the off-diagonal body↔pili coupling blocks. The Brownian covariance path, by contrast, uses the symmetrised effective body mobility `M_eff = 0.5*(M + M')` to satisfy the fluctuation-dissipation requirement of a symmetric diffusion tensor.

This operator splitting therefore relies on the approximation that the non-reciprocal component is small. The implementation measures the relative asymmetry `rel_asym = ||M_eff - M_eff^T||_F / ||M_eff||_F` at every Brownian step and emits a warning when `rel_asym > 1e-3`. For typical mixed-epsilon configurations `rel_asym ~ 1e-5..1e-3`; for pure-RSM (no pili) systems it drops to `<1e-10` (LU round-off only). The Schur-complement extraction from the full `M_weighted` to the 6×6 body block further attenuates the non-symmetry, so the practical impact on the equilibrium distribution is bounded by `rel_asym` itself. For configurations where `eps_body ≈ eps_pili` the approximation becomes exact. Users seeking the strictest statistical fidelity should monitor the `[BROWN]` asymmetry log lines and, if `rel_asym > 1e-2`, consider tightening `eps_body` toward `eps_pili` (or vice versa) provided the body-surface resolution `N_body` is adjusted to keep the RSM leak within tolerance (see §5.1).

## 12. Walker Scaling Consistency

When the coupled problem is reduced to a single free elastic filament without the body, the nondimensional structure is designed to remain consistent with the Walker-style Kirchhoff-rod formulation:

- The spatial $Q$ matrix has the same role: it maps body-frame or rod-frame generalized rates into translational and angular velocities along the filament.
- The force-balance rows use trapezoidal quadrature weights, while the pilus moment-balance rows use the per-rod length scaling.
- Elastic and active moments are stored in the per-pilus arclength coordinate $s_k\in[0,1]$.

For torsional resistance, the dimensional segment relation is proportional to the local segment length:

```math
\tau_{\mathrm{twist},j}
\sim
c_t\,\Delta s_k\,\dot{\psi}_j,
\qquad
c_t \sim 4\pi\mu r_{\mathrm{pili}}^2.
```

Using the global project scales gives the nondimensional torsional coefficient:

```math
\frac{c_t\,\Delta s_k/T_0}{EI/L_0}
\sim
\frac{\varepsilon^2}{2}\,\Delta \hat{s}_k.
```

The implementation stores each pilus on its own normalized arclength, so the conversion between the global body scale and the per-pilus Walker scale introduces the pilus length ratio $\ell_k = L_{\mathrm{pili},k}/L_0$. Per-pilus slenderness is $\varepsilon_k = \varepsilon/\ell_k = r_{\mathrm{pili}}/L_{\mathrm{pili},k}$ (`build_global_resistance.m`).

```math
\widetilde{\mathbf{A}}_{\mathrm{twist},k}
=
\frac{\ell_k\varepsilon_k^2}{2}
\widehat{\mathbf{A}}_k
=
\frac{\varepsilon^2}{2\ell_k}
\widehat{\mathbf{A}}_k.
```

The two right-hand forms are algebraically equivalent because $\ell_k\varepsilon_k^2 = \varepsilon^2/\ell_k$.

The complementary $\ell_k^3$ factor used in each pilus moment-balance row converts the per-rod moment equations back to the global scale, keeping the assembled system

```math
\mathbf{L}\dot{\mathbf{z}} = \mathbf{R}
```

dimensionally homogeneous.

## 13. Validation Scope

The codebase has been checked against the following model-level invariants:

- Quaternion convention and body orientation kinematics.
- RSM kernel scaling and body-volume consistency.
- RSS recurrence terms and segment matrix symmetry checks.
- Rotlet anti-symmetry and recurrence behavior.
- Walker-style Euler-angle `Q` matrix and moment-balance scaling.
- Clamped and free-torsion root boundary constraints.
- Multi-pilus state layout, geometry reconstruction, and matrix dimensions.
- Full-coupled effective body mobility and body-only Brownian Cholesky positive-definiteness checks.
- Weighted translation/twist reciprocity and symmetric power dissipation.
- Scale-independent linear-solve backward residuals, selected-state `rcond`,
  finite-value checks, and the conditioning of the exact multi-motor
  torque-speed linear solve.
- Output units for MAT, CSV, figure, and log files.

Backward residuals above \(10^{-10}\) warn and values above \(10^{-6}\)
abort.  Coupled-matrix `rcond` below `1e-10` or `1e-14` warns and is
recorded; a hard abort requires the joint gate of residual \(>10^{-6}\)
and `rcond<1e-14`.  Measured extrema and the fixed thresholds are saved
in `results.diagnostics`.
