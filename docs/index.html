细菌胞体-纤毛耦合弹性流体动力学仿真 Coupled Body-Pili Elastohydrodynamic Simulation

A MATLAB simulation framework for modelling capsule-shaped bacteria with elastic pili sinking in Stokes flow. Combines regularized Stokeslet methods (RSM + RSS + Rotlet segments), Kirchhoff elastic rods with configurable intrinsic curvature and time-varying active moments, full-system effective-friction Brownian dynamics, steady background flow, adaptive Euler-angle singularity avoidance, 3D visualization and animation, JSON configuration, 8 batch parameter-sweep scripts, and automated post-processing to Excel summaries. 一个基于 MATLAB 的仿真框架，用于模拟携带弹性纤毛的胶囊状细菌在 Stokes 流体中的沉降运动。 融合正则化 Stokeslet 方法（RSM + RSS + Rotlet 线段）、Kirchhoff 弹性杆（可配置固有曲率与时变主动力矩）、 全系统有效摩擦布朗动力学、稳态背景流场、自适应欧拉角奇点规避、三维可视化与动画、 JSON 配置系统、8 个批量参数扫描脚本，以及自动化后处理 Excel 汇总。

Project Overview项目概述

This project simulates a capsule-shaped bacterium (rigid body with hemispherical caps) bearing one or more clamped elastic pili (Kirchhoff rods) as it sediments under gravity in a viscous Stokes-flow environment at the micro-scale. The full hydrodynamic coupling between the body surface and every pili filament is resolved at each time step. 本项目模拟携带一根或多根弹性纤毛（Kirchhoff 弹性杆）的胶囊状细菌（带半球端盖的刚性体） 在微尺度粘性 Stokes 流体环境中受重力作用的沉降运动。每一时间步均求解胞体表面与所有纤毛之间的完整流体动力耦合。

Physical Setup物理模型

Capsule body胶囊胞体 — Rigid spherocylinder, RSM (Regularized Stokeslet Method) surface discretisation with $N_\text{body}$ force points. Orientation tracked via unit quaternion $\mathbf{q}$. 刚性球柱体，采用 RSM（正则化 Stokeslet 方法）进行表面离散，共 $N_\text{body}$ 个力点。方向通过单位四元数 $\mathbf{q}$ 追踪。

Elastic pili弹性纤毛 — Kirchhoff inextensible rods, RSS (Regularized Stokeslet Segments) + Rotlet line segments. Euler-angle parameterisation per segment. Kirchhoff 不可伸长弹性杆，采用 RSS（正则化 Stokeslet 线段）+ Rotlet 线段。每段使用欧拉角参数化。

Clamped boundary固支边界 — Pili root rigidly attached to the body surface; dual enforcement via kinematic rate constraints + geometric projection. 纤毛根部刚性连接于胞体表面；通过运动学速率约束与几何投影双重保障固支条件。

Brownian motion布朗运动 — Thermal fluctuations applied to the body using a full-system effective friction tensor that naturally includes pili drag. 基于全系统有效摩擦张量为胞体施加热涨落，该张量自然包含纤毛带来的额外阻力。

Theoretical Foundations理论基础

3a Stokes Flow & Regularized Methods Stokes 流动与正则化方法

At micro-scale ($\text{Re} \ll 1$), inertia is negligible and fluid motion is governed by the Stokes equations. The velocity field due to a regularized point force $\mathbf{f}$ at $\mathbf{x}_0$ is given by the regularized Stokeslet: 在微尺度 ($\text{Re} \ll 1$) 下，惯性可忽略，流体运动由 Stokes 方程描述。 位于 $\mathbf{x}_0$ 处的正则化点力 $\mathbf{f}$ 产生的速度场由正则化 Stokeslet 给出：

$$\mathbf{u}(\mathbf{x}) = \frac{1}{8\pi\mu} \left[ \frac{|\mathbf{r}|^2 + 2\varepsilon^2}{\left(|\mathbf{r}|^2 + \varepsilon^2\right)^{3/2}} \mathbf{I} + \frac{\mathbf{r}\mathbf{r}^\top}{\left(|\mathbf{r}|^2 + \varepsilon^2\right)^{3/2}} \right] \mathbf{f}$$

where $\mathbf{r} = \mathbf{x} - \mathbf{x}_0$ and $\varepsilon$ is the regularization parameter. 其中 $\mathbf{r} = \mathbf{x} - \mathbf{x}_0$，$\varepsilon$ 为正则化参数。

RSM — Body SurfaceRSM — 胞体表面

The capsule body is discretised into $N_\text{body}$ surface points. Each carries a regularized Stokeslet, forming the $3N_\text{body} \times 3N_\text{body}$ mobility matrix $\mathbf{M}_{BB}$. 胶囊胞体被离散为 $N_\text{body}$ 个表面力点。每个力点携带一个正则化 Stokeslet，构成 $3N_\text{body} \times 3N_\text{body}$ 迁移率矩阵 $\mathbf{M}_{BB}$。

RSS — Pili FilamentsRSS — 纤毛丝

Each pili segment uses exact line-segment integration of the Stokeslet kernel (Cortez 2018), plus Rotlet line segments for twist–translation coupling. This decouples $\varepsilon$ from segment length $h$. 每段纤毛对 Stokeslet 核进行精确线段积分 (Cortez 2018)，并叠加 Rotlet 线段以捕捉扭转-平动耦合。这使 $\varepsilon$ 与线段长度 $h$ 解耦。

3b Kirchhoff Elastic Rod Model Kirchhoff 弹性杆模型

Each pilus is modelled as an inextensible Kirchhoff elastic rod. The centreline orientation is parameterised by Euler angles $(\theta_j, \phi_j, \psi_j)$ at each segment $j$, defining a material frame $\{\mathbf{d}_1, \mathbf{d}_2, \mathbf{d}_3\}$. The elastic restoring moments are: 每根纤毛被建模为不可伸长的 Kirchhoff 弹性杆。中心线方向由每段 $j$ 的欧拉角 $(\theta_j, \phi_j, \psi_j)$ 参数化， 定义材料标架 $\{\mathbf{d}_1, \mathbf{d}_2, \mathbf{d}_3\}$。弹性恢复力矩为：

$$m_1 = EI\!\left(\frac{\partial \theta}{\partial s} - \kappa_1^0\right), \quad m_2 = EI\!\left(\sin\theta\,\frac{\partial \phi}{\partial s} - \kappa_2^0\right), \quad m_3 = \frac{EI}{1+\sigma}\!\left(\frac{\partial \psi}{\partial s} + \cos\theta\,\frac{\partial \phi}{\partial s} - \kappa_3^0\right)$$

where $EI$ is the bending stiffness, $\sigma$ is the Poisson ratio giving torsional stiffness $GJ = EI/(1+\sigma)$, and $\kappa_\alpha^0$ are the intrinsic (stress-free) curvatures. 其中 $EI$ 为弯曲刚度，$\sigma$ 为泊松比，扭转刚度 $GJ = EI/(1+\sigma)$， $\kappa_\alpha^0$ 为固有（无应力状态下的）曲率。

New in v5.0 — Configurable Intrinsic Curvature v5.0 新增 — 可配置固有曲率

The intrinsic curvature $\kappa_\alpha^0$ can now be set independently per pilus: frozen (keep initial geometry), zero (straight rest shape), constant (user-specified $[\kappa_1^0, \kappa_2^0, \kappa_3^0]$), or helix (helical curvature from $\kappa_{d2}$/$\kappa_{d3}$). 固有曲率 $\kappa_\alpha^0$ 现可逐纤毛独立设置： frozen（保持初始几何）、zero（直线静息形状）、 constant（用户指定 $[\kappa_1^0, \kappa_2^0, \kappa_3^0]$） 或 helix（通过 $\kappa_{d2}$/$\kappa_{d3}$ 设定螺旋曲率）。

3c Coupled Linear System 耦合线性系统

The body and pili degrees of freedom are coupled through hydrodynamic interactions into a single generalized linear system: 胞体和纤毛的自由度通过流体动力学交互耦合为统一的广义线性系统：

$$\underbrace{-\mathbf{B}\,\mathbf{M}_\text{weighted}^{-1}\,\mathbf{Q}}_{\textstyle\text{lin\_sys}\;=\;-\boldsymbol{\Xi}_\text{gen}}\;\dot{\mathbf{z}} = \mathbf{R}$$

Q MatrixQ 矩阵

Maps generalised velocities $\dot{\mathbf{z}}$ (body velocity + Euler-angle rates) to spatial velocities at all surface/node points. 将广义速度 $\dot{\mathbf{z}}$（胞体速度 + 欧拉角速率）映射到所有表面/节点的空间速度。

B MatrixB 矩阵

Maps distributed surface/node forces back to generalised forces/moments (force & moment balance). 将分布式表面/节点力映射回广义力与力矩（力与力矩平衡）。

R VectorR 向量

Right-hand side: gravitational force $-E_g\,\hat{\mathbf{g}}$, elastic restoring moments, active moments $\mathbf{M}_\text{act}$ (v5.0), and background flow contribution $\mathbf{B}\,\mathbf{A}^{-1}\,\mathbf{u}_\text{bg}$ (v5.0). 右端项：重力 $-E_g\,\hat{\mathbf{g}}$、弹性恢复力矩、主动力矩 $\mathbf{M}_\text{act}$（v5.0）以及背景流贡献 $\mathbf{B}\,\mathbf{A}^{-1}\,\mathbf{u}_\text{bg}$（v5.0）。

3d Nondimensionalization 无量纲化

All state variables are nondimensionalized using bending-stiffness-based characteristic scales: 所有状态变量均采用基于弯曲刚度的特征尺度进行无量纲化：

Brownian Dynamics Scheme布朗动力学方案

Physical Motivation物理动机

In the overdamped regime ($\text{Re} \ll 1$), the body experiences thermal fluctuations governed by the fluctuation-dissipation theorem (FDT). The effective friction of the body is not determined by the body alone — pili attached to the body contribute additional hydrodynamic drag. More and longer pili increase the effective friction and correspondingly reduce thermal diffusion. This coupling is captured through the Schur complement of the full-system generalised resistance matrix. 在过阻尼区域 ($\text{Re} \ll 1$) 中，胞体受涨落耗散定理 (FDT) 支配的热涨落驱动。 胞体的有效摩擦不仅取决于胞体本身——附着于胞体的纤毛贡献了额外的流体动力学阻力。 纤毛越多、越长，有效摩擦越大，相应的热扩散越弱。 该耦合通过全系统广义阻力矩阵的 Schur 补来捕捉。

$$\mathbf{M}_\text{eff} = \left[\boldsymbol{\Xi}_\text{gen}^{-1}\right]_{BB} = \left(\boldsymbol{\Xi}_{BB} - \boldsymbol{\Xi}_{BP}\,\boldsymbol{\Xi}_{PP}^{-1}\,\boldsymbol{\Xi}_{PB}\right)^{-1}$$

The Schur complement $\boldsymbol{\Xi}_{BB} - \boldsymbol{\Xi}_{BP}\,\boldsymbol{\Xi}_{PP}^{-1}\,\boldsymbol{\Xi}_{PB}$ is the effective body resistance after eliminating pili DOFs. Since the full system includes hydrodynamic coupling from the pili, the resulting body mobility $\mathbf{M}_\text{eff}$ is smaller (more damped) than the isolated body's mobility. Schur 补 $\boldsymbol{\Xi}_{BB} - \boldsymbol{\Xi}_{BP}\,\boldsymbol{\Xi}_{PP}^{-1}\,\boldsymbol{\Xi}_{PB}$ 为消除纤毛自由度后胞体的有效阻力。由于全系统包含纤毛的流体动力学耦合，所得胞体迁移率 $\mathbf{M}_\text{eff}$ 小于（阻尼更大）孤立胞体的迁移率。

Probing Method — Extracting Effective Mobility 探测法 — 提取有效迁移率

Rather than explicitly inverting the full $n \times n$ resistance matrix, we extract the 6×6 body mobility block by solving the coupled linear system with 6 unit probe vectors: 无需显式求逆整个 $n \times n$ 阻力矩阵，而是通过求解耦合线性系统的 6 个单位探测向量来提取 6×6 胞体迁移率块： 

% Assemble coupled linear system (Steps 1-7)
[lin_sys, ~] = build_coupled_lin_sys(Z, params);

% Probe with 6 unit body forces/torques
R_probe = zeros(n_state, 6);
R_probe(1:6, 1:6) = -eye(6);   % lin_sys = -Xi_gen

z_dot_probe = lin_sys \ R_probe;
M_eff_dimless = z_dot_probe(1:6, :);  % 6x6 effective mobility

The dimensionless mobility is then converted to physical units: 无量纲迁移率随后被转换为有量纲物理单位：

$$M_\text{eff,dim}(i,j) = \frac{\tilde{M}_\text{eff}(i,j)}{S_i \, S_j}, \qquad \mathbf{S} = \bigl[\underbrace{\sqrt{8\pi\mu L_0}}_{\text{translation}\;\times 3},\; \underbrace{\sqrt{8\pi\mu L_0^3}}_{\text{rotation}\;\times 3}\bigr]^\top$$

Diffusion Tensor & Euler-Maruyama Discretisation 扩散张量与 Euler-Maruyama 离散化

$$\mathbf{D}_\text{eff} = k_B T\,\mathbf{M}_\text{eff}, \qquad \mathbf{L}_\text{eff}\,\mathbf{L}_\text{eff}^\top = 2\,\mathbf{D}_\text{eff}, \qquad \delta\mathbf{U} = \mathbf{L}_\text{eff}\,\boldsymbol{\eta}\,\sqrt{\Delta t_B}, \quad \boldsymbol{\eta} \sim \mathcal{N}(\mathbf{0},\,\mathbf{I}_6)$$

The 6D displacement $\delta\mathbf{U}$ contains both translational ($\delta\mathbf{X}$, in metres) and rotational ($\delta\boldsymbol{\omega}$, in radians) components, coupled through the off-diagonal blocks of $\mathbf{L}_\text{eff}$. The rotation is applied via quaternion composition: $\mathbf{q}_{n+1} = \Delta\mathbf{q}\,\otimes\,\mathbf{q}_n$. 6D 位移 $\delta\mathbf{U}$ 包含平动分量 ($\delta\mathbf{X}$，单位：米) 和转动分量 ($\delta\boldsymbol{\omega}$，单位：弧度)，通过 $\mathbf{L}_\text{eff}$ 的非对角块耦合。 转动通过四元数复合施加：$\mathbf{q}_{n+1} = \Delta\mathbf{q}\,\otimes\,\mathbf{q}_n$。

When $\mathbf{M}_\text{eff}$ depends on the configuration (as it does here — pili change shape over time), the Itô form of the overdamped SDE acquires a spurious drift term $k_B T\,\nabla_{\!\mathbf{q}}\!\cdot\!\mathbf{M}_\text{eff}$. Directly computing this divergence requires $O(n)$ additional linear solves, which is prohibitively expensive. 当 $\mathbf{M}_\text{eff}$ 依赖于构型时（此处确实如此——纤毛形状随时间变化）， 过阻尼 SDE 的 Itô 形式会产生一个伪漂移项 $k_B T\,\nabla_{\!\mathbf{q}}\!\cdot\!\mathbf{M}_\text{eff}$。直接计算此散度 需要 $O(n)$ 次额外线性求解，计算成本过高。

The Fixman midpoint scheme captures this drift implicitly: Fixman 中点格式隐式捕捉该漂移：

  1. Compute $\mathbf{L}_n$ at current configuration $\mathbf{q}_n$在当前构型 $\mathbf{q}_n$ 处计算 $\mathbf{L}_n$
  2. Draw random vector $\boldsymbol{\eta} \sim \mathcal{N}(\mathbf{0},\,\mathbf{I}_6)$生成随机向量 $\boldsymbol{\eta} \sim \mathcal{N}(\mathbf{0},\,\mathbf{I}_6)$
  3. Trial kick: $\Delta\mathbf{U}_\text{trial} = \mathbf{L}_n\,\boldsymbol{\eta}\,\sqrt{\Delta t_B}$试探步：$\Delta\mathbf{U}_\text{trial} = \mathbf{L}_n\,\boldsymbol{\eta}\,\sqrt{\Delta t_B}$
  4. Half-step: $\mathbf{q}_\text{mid} = \mathbf{q}_n + \tfrac{1}{2}\,\Delta\mathbf{U}_\text{trial}$半步推进：$\mathbf{q}_\text{mid} = \mathbf{q}_n + \tfrac{1}{2}\,\Delta\mathbf{U}_\text{trial}$
  5. Recompute $\mathbf{L}_\text{mid}$ at midpoint configuration在中点构型处重新计算 $\mathbf{L}_\text{mid}$
  6. Final kick: $\Delta\mathbf{U} = \mathbf{L}_\text{mid}\,\boldsymbol{\eta}\,\sqrt{\Delta t_B}$ — same $\boldsymbol{\eta}$!最终位移：$\Delta\mathbf{U} = \mathbf{L}_\text{mid}\,\boldsymbol{\eta}\,\sqrt{\Delta t_B}$ — 使用相同的 $\boldsymbol{\eta}$！

Cost: 2× linear system solve per Brownian step. Controlled via fixman_midpoint in the JSON config. 代价：每个布朗步需 2 次线性求解。通过 JSON 配置中的 fixman_midpoint 控制。

5a Intrinsic Curvature (Per-Pilus, Static) 固有曲率（逐纤毛、静态）

The stress-free curvature $\kappa_\alpha^0$ defines the natural resting shape of each filament. When deformed away from this shape, elastic restoring moments $m_\alpha = EI(\kappa_\alpha - \kappa_\alpha^0)$ arise. The intrinsic curvature does not vary with time but can differ between pili. 无应力曲率 $\kappa_\alpha^0$ 定义每根纤毛的自然静息形状。 当偏离此形状时，弹性恢复力矩 $m_\alpha = EI(\kappa_\alpha - \kappa_\alpha^0)$ 产生。 固有曲率不随时间变化，但可为不同纤毛设置不同值。

5c Background Flow (Global, Steady) 背景流场（全局、稳态）

A time-invariant background flow $\mathbf{u}_\infty(\mathbf{x})$ can be imposed on the system. It enters the coupled system as an additional RHS term computed from the background velocities evaluated at all hydrodynamic points (body + pili): 可向系统施加时不变背景流 $\mathbf{u}_\infty(\mathbf{x})$。 它通过在所有流体力学评估点（胞体 + 纤毛）处计算的背景速度，以额外右端项的形式进入耦合系统：

$$\text{flow contribution} = \mathbf{B}\,\mathbf{A}^{-1}\,\mathbf{u}_\text{bg}$$

where $\mathbf{u}_\text{bg}$ contains both the translational velocities ($3N_\text{total}$ components) and the twist projections (vorticity projected onto each pili segment's tangent vector). 其中 $\mathbf{u}_\text{bg}$ 包含平动速度（$3N_\text{total}$ 个分量）和扭转投影（涡度在各纤毛段切向量上的投影）。

Uniform Flow均匀流

Spatially constant: $\mathbf{u}_\infty = U_\text{max}\,\hat{\mathbf{d}}$. Specify U_max [m/s] and direction $[d_x, d_y, d_z]$. 空间均匀：$\mathbf{u}_\infty = U_\text{max}\,\hat{\mathbf{d}}$。指定 U_max [m/s] 和 direction $[d_x, d_y, d_z]$。

Shear Flow (shear_z)剪切流 (shear_z)

Piecewise-linear shear: $u = U_\text{max}\min(1,\,\max(0,\,z/H))$ along a configurable shear_axis. Generates vorticity for pili twist. 分段线性剪切：$u = U_\text{max}\min(1,\,\max(0,\,z/H))$，沿可配置的 shear_axis 方向。为纤毛扭转产生涡度。 

% Example: Piecewise-linear shear flow in z-direction
cfg.background_flow.type           = 'shear_z';
cfg.background_flow.U_max          = 10e-6;       % [m/s]
cfg.background_flow.shear_axis     = [1 0 0];     % flow along x
cfg.background_flow.shear_height_m = 20e-6;       % [m]

U_max is pre-converted to dimensionless via $U_0 = EI/(8\pi\mu L_0^2)$. The background flow does not affect the Brownian diffusion tensor. U_max 通过 $U_0 = EI/(8\pi\mu L_0^2)$ 预转换为无量纲值。 背景流不影响布朗扩散张量。

Updated Coupled System (v5.0)更新后的耦合系统（v5.0）

The full right-hand side of the coupled linear system now includes four contributions: 耦合线性系统的完整右端项现包含四项贡献：

$$-\mathbf{B}\,\mathbf{M}_\text{w}^{-1}\,\mathbf{Q}\;\dot{\mathbf{z}} = \underbrace{-E_g\,\hat{\mathbf{g}}}_{\text{gravity}} + \underbrace{\mathbf{m}(\kappa - \kappa^0)}_{\text{elastic}} - \underbrace{\mathbf{M}_\text{act}(t)}_{\text{active}} - \underbrace{\mathbf{B}\,\mathbf{A}^{-1}\,\mathbf{u}_\text{bg}}_{\text{flow}}$$

When all three features are set to default (off/frozen), the system reduces to the original v4.x formulation identically. 当三项功能均设为默认值（off/frozen）时， 系统退化为与 v4.x 完全相同的原始形式。

Three Ways to Run三种运行方式

Edit parameters directly in main_coupled_simulation.m, then press Run: 直接在 main_coupled_simulation.m 中编辑参数，然后运行： 

cfg.case_name    = 'TwoPili-S29-L3-Brown';
cfg.minor_axis   = 0.4e-6;       % [m]
cfg.major_axis   = 1.25e-6;      % [m]
cfg.N_body       = 200;
cfg.enable_brown = true;
cfg.Temper       = 293.15;       % [K]
cfg.dt_B         = cfg.dt / 2;
cfg.fixman_midpoint = false;

% v5.0 — Background flow (default: off)
cfg.background_flow.type = 'off';

% v5.0 — Per-pili intrinsic curvature / active moment
pili_config(1).intrinsic_curvature = 'frozen';
pili_config(1).active_moment = struct('type', 'off');

[cfg.Pili_Matrix, cfg.pili_ext] = parse_pili_config(pili_config);
[results, params, output_dir]   = run_simulation(cfg);

Load configuration from a JSON file: 从 JSON 文件加载配置： 

config_file = 'configs/OnePili-P1-L3.json';
cfg = load_sim_config(config_file);
[results, params, output_dir] = run_simulation(cfg);
