# ==============================================================================
# 1. Core Simulation Runtime (Required)
# ==============================================================================
# - MATLAB R2022a or later (developed and tested on R2026a on Windows 11 and
#   R2023a on Linux HPC clusters).
#   * Earlier releases are unsupported: runs use jsonencode(..., 'PrettyPrint',
#     true) (R2021a) and clim() in flow-field figures (R2022a).
#   * Base MATLAB only: NO Statistics and Machine Learning Toolbox, NO MEX
#     compiler, and NO Python / Conda / pip environment are required to run
#     simulations or the CPC verification suite.
#   * Not compatible with GNU Octave (relies on MATLAB decomposition, ode15s,
#     and exportgraphics).
#
# - Bundled Third-Party MATLAB Package (Included — no manual download needed):
#   * S2 Sampling Toolbox ("Suite of functions to perform uniform sampling of
#     a sphere", MIT License, Copyright (c) 2019 Anton Semechko), bundled under
#     MATLAB Add-On/Suite of functions to perform uniform sampling of a sphere/.
#     Added automatically by cpc/run_cpc_tests.m and validation drivers.

# ==============================================================================
# 2. Optional MATLAB Toolboxes & Hardware Acceleration
# ==============================================================================
# - Parallel Computing Toolbox (optional):
#   * Accelerates multi-worker Brownian ensembles and JSON parameter sweeps in
#     batch_sweep/ (parfor) and multi-frame flow-field streamline computation
#     (parpool('Threads'), use_parallel = 'auto').
#   * Falls back seamlessly to serial CPU execution when absent.
#
# - CUDA-capable NVIDIA GPU with FP64 support (optional):
#   * Accelerates batched 3-plane flow-field velocity reconstruction in
#     render_flowfield_from_results / flowfield_grid_velocity (use_gpu = 'auto').
#   * Falls back seamlessly to CPU BLAS3 when absent.
#
# - Optional interactive HTML figure export (exportgraphics -> .html):
#   * Requires MATLAB R2026a or later; PNG and vector PDF work on R2022a+.

# ==============================================================================
# 3. Optional Python Packages (Publication Re-plotting Scripts ONLY)
