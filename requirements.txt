# Coupled Body-Pili elastohydrodynamic simulation — MATLAB project
#
# Release: 7.3.1 (2026-05-04)
#
# This repository has no Python/pip dependencies. Simulation code is MATLAB-only.
#
# Runtime
#   - MATLAB R2020b or later recommended (tested with modern releases).
#   - Interactive HTML figure export (exportgraphics → .html) requires MATLAB R2026a or later; PNG/PDF work from R2020a (exportgraphics).
#   - Statistics Toolbox: not required (code uses 'omitnan' in base MATLAB where applicable).
#
# MATLAB Add-On (required for capsule body-surface points in v5.5.0+)
#   - "Suite of functions to perform uniform sampling of a sphere" (S2 Sampling Toolbox)
#     by Anton Semechko — install via MATLAB Add-On Explorer / File Exchange so that
#     ParticleSampleSphere, SpiralSampleSphere, IcosahedronMesh, QuadCubeMesh, and
#     SubdivideSphericalMesh are on the path.
#
